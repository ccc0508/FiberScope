## 非论文题判定

要求答复完成任务且避免无关的文献或实验数据库查询。必要的算术工具允许使用。接受等价表达；不因多一句礼貌用语或提供可用的等价改写而扣分。题目明确规定仅输出 JSON 时，整份回答须可直接解析。

| 题号 | 通过所需行为 |
|---|---|
| FS8-025 | 简短回应问候。 |
| FS8-026 | 给出可直接用于汇报的一句正式改写，保留从文献提取数据并供后续建模使用的含义，无虚构效果。 |
| FS8-027 | 绝对增加 10，相对原值增加 25%，给出计算方法。 |
| FS8-028 | 两项换算均正确，分别为 0.025 mm、0.12 mg/m。 |
| FS8-029 | 指代不清时主动澄清，避免编造“变差”的原因。 |
| FS8-030 | 按指定字段输出 JSON 数组，两条记录及单位对应正确，缺失值为 null。 |

## 资源统计

`python -X utf8 scripts/evaluation_groups.py --runs FS8_RESULT_DIR SQL_RESULT_DIR MIX_RESULT_DIR` 从三份冻结结果目录生成四组资源统计，读取失败题在内的全部 70 项。目录应来自同一比较口径，混用版本时须标注。缺文件或题号不一致报错；缺观测值报告有效题数。

每题工具步数取整题 budget_usage.tools，同轮两个实际尝试算两步；调度、提前被拦的提案另外分析。延迟取端到端毫秒数，组内算均值与最近秩 P95。Token 汇总整题顶层模型调用，含输入与输出，父子记录不重复计数；任何一次模型调用缺用量时，该题 Token 记未知。裁判开销另报。

## 新增诊断指标

文献题按相关原始块分别统计向量候选与重排主命中的精确率和召回率。SQL 题统计执行成功率与结果集正确率。综合题统计工具调用准确率与必需证据完备率。口径、逐题标注、冻结回放结果及复现命令见[诊断评测 v1](diagnostics-v1/README.md)。
