## 主要失败与缺陷

- 16题执行失败：3题Planner格式、11题子Agent交接格式、2题SQL子Agent模型连接异常。格式包括空参数、错误嵌套、额外字段、Markdown代码围栏和损坏JSON。详见failure-diagnosis.json。
- RAG失败：4、8、9、13、20。23、24误路由为直接回答，未核查论文。17没有确认Morais表1单位；19没有取得Pennells验证证据。14把相对降幅4.66%误写为4.66个百分点，已校准Jev漏检。
- SQL失败：5、8、12、14；其中12在Planner失败。16能澄清但未解释库中只有累计转数而非rpm，扣2分。其余完成答案按最新口径核对核心结果、粒度、单位和来源。
- 综合失败：4、6、13、14、17、18、20。17、18为APIConnectionError，其余是结构化交接问题。
- 综合5、9、10、12、15、16缺少部分明确要求的查询或论文结果；8已看图但读数错误；9把论文编号用于目录/失败SQL的说明，编号存在不等于引用语义正确；10对汇总视图COUNT=1误推原始有效观测只有1个。
- 部分回答把“尚未确认相同”说成“已经不同”，或在扩写时出现前后矛盾。不能只靠必答要点判断整体质量。

下一步优先修复路由/交接格式处理，并用冻结失败输出离线验证；随后处理子任务完成度与来源类型对应，再考虑扩大检索或提高预算。本轮没有据这些结果修改运行时代码。

## 交付与复现

- report.html：70题、完整最终回答、考查要求、Jev原评、校准及轨迹摘要。
- results.json：精简审计包，包含校准理由和每份原始结果SHA256。
- summary.json：分组统计、预算、用量、冻结配置与一致性核验。
- sql-references.json：本轮开始时冻结的实际数据库参考查询结果。
- failure-diagnosis.json：离线重放结构校验的失败原因，不调用模型。
