# Evidence checks v5

Adds bounded, source-linked checks to literature coverage items. Data provenance comparisons distinguish study object, generation method, and validation; sample scope is conditional. Causal questions additionally check author explanations, measurement limitations and confounders where relevant. Existing evidence is reused before targeted follow-up; unknown origin remains unknown.

Table ranges require labelled component values before min/max. Final synthesis checks exclusivity and consistency against details; provenance wording does not assume measurements. No fixed disclaimer, question-specific answers or mandatory keyword searches are introduced.

Checks persist inside child results and coverage reports and reach the parent. A missing/partial or structurally invalid declared check downgrades a self-reported verified requirement and uses the existing single bounded coverage retry. No extra reviewer call or budget increase. SQL instructions unchanged; final synthesis shares the numerical/consistency rules.

Limits: checks remain model-selected (empty checks remain accepted for compatibility and unrelated questions). The program verifies supplied records and delivered reference availability, not semantic completeness or arithmetic truth. A model can still omit a necessary check or wrongly mark it verified; this is not a guarantee of correction. Added prompt and output tokens must be measured in subsequent evaluation.

Validation: 36 existing/new coordinator, routing and coverage tests passed. Added cases cover an unresolved origin overriding verified and unavailable evidence in a numerical check. No paid end-to-end evaluation rerun or server deployment in this change.
