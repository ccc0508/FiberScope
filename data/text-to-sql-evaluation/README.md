# Text-to-SQL 开发基线 v1

20题固定开发/回归题，不是隐藏测试集。覆盖样本计数、精确筛选、Top-K、NULL聚合、复配比例、纯浆端点、来源连接、连接去重、子查询、再生粒度、空结果、全量聚合、质量状态、不确定单位、歧义澄清、换算、相对变化、只读权限和缺失能力/因果边界。

`cases-v1.json` 包含题目、参考SQL、人工判定要求。参考SQL只用于在同一只读事务中生成参考结果，绝不提供给答题模型。每题独立新上下文，沿用当前Agent、真实8篇论文目录和正常工具预算；不为测试另加答案提示。所有题只答一次，失败保留；断点续跑复用已有答案，不挑选最好结果。

执行：`.venv/Scripts/python.exe -X utf8 scripts/evaluate_text_to_sql_baseline.py --run sql-baseline-v1-20261107`。默认2题并行，可用 `--workers 1` 串行。输出保存在被忽略的 `.rag-data/text-to-sql-evaluation/<run>/`；完整轨迹在 `.rag-data/agent-runs/`。保存代码哈希、题目哈希、视图数据哈希、参考结果、每题工具调用和模型usage。原始凭据不会写入报告。

## 固定评分规则（每题10分）

- 结果/核心行为：0—4分。数值和对象全部正确4，主要正确但遗漏或局部错误2—3，实质错误1，完全错误0。歧义、只读和缺字段题评是否正确澄清/拒绝/指出缺失。
- 查询口径与条件：0—3分。视图粒度、筛选、连接去重、NULL、全量统计都正确3；有轻微不清2；严重混淆1或0。不能仅凭SQL执行成功给满分。
- 单位与解释：0—2分。单位、换算、不确定性和解释无实质错误2；局部遗漏1；单位错误或虚构因果0。不需要单位的题以边界解释正确性评分。
- 来源可追溯：0—1分。数据库结论可追溯至正确查询且引用有效1；漏关键来源/错配0。合理澄清或拒绝不强制添加引用；已明确覆盖同一结论的表格或段落不要求每句重复引用。

按所有20题计算分数，不丢弃失败题。数量精确匹配；连续量采用题目给定容差，未指定默认绝对误差0.01；允许不同但等价的SQL。人工校准逐题写出依据及实质扣分，不用字面匹配答案。评审者可查看题目、参考查询、执行结果和完整答题轨迹。

另外报告完成率、SQL调用执行成功率、引用检查通过率。以上指标不得替代结果正确率。模型usage按供应商实际返回记录；费用和端到端耗时若缺少可信记录则标为未知，不估造。
