# SQL＋RAG 综合题 v1（仅出题，未运行）

20道开发验证题，目标是检验一层Planner、SQL子Agent与文献子Agent的协作。MIX01—16为数据与论文整合，MIX17—19为精确空结果、缺失能力和错误前提，MIX20为澄清优先任务。全部涉及实验与文献语境，但不要求每题机械调用两路：MIX20可以先澄清后暂停。

## 文件与使用

- `QUESTIONS.md`：完整纯题目，适合人工阅读。
- `questions.jsonl`：仅id/question，用于未来答题输入；每题使用独立上下文。
- `cases-v1.json`：含分类、涉及论文和考查点，仅供评测者使用，不整份提供给答题模型。

本轮仅根据现有视图目录、已保存的20题SQL基线及30题文献回归材料编写题目，未执行数据库查询、文献检索、模型调用或评测，未生成候选回答和分数。考查点是评测设计，不是已核实的标准答案。正式评分前须独立核对原论文、冻结数据库结果及参考答案；尤其不得将既有模型回答自动作为金标准。

这是公开开发题，不是holdout；也不能以这一批题覆盖已知所有故障。未编造新的论文、字段或实验条件。必要信息不足时，正确回答可以是澄清、拒绝不当合并或说明无法确认，不应强迫给数值。

## 建议评估项（本轮不评分）

路由及必要澄清；SQL筛选/统计粒度/NULL/单位；论文事实与图表理解；跨来源映射；条件、测量定义与因果边界；引用对应；工具预算和重复调用。程序运行成功与实质回答正确分开记录。允许等价查询、不同合理检索路径，不要求固定工具次数；混合回答应区分数据库快照、论文证据、计算与建议。

不能直接套用单一数值比较评分。查询结果准确但据论文夸大项目因果，应独立记录融合解释错误；合理澄清不因缺少数值而扣分；同一段落已经清楚覆盖的来源不要求逐句重复引用。
