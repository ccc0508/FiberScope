# FSX-002

Li、Hu与Shao（2023）摘要报告曲线拟合模型prediction的RMSE为0.1667；Ayaliew等（2026）报告ANN的RMSE约31.6 MPa。有人据此说前者预测更准。请核对两篇论文各自预测什么、这些误差对应什么数据，并判断能否仅按这两个RMSE数值排名。

**结论：不能只按这两个 RMSE 数值排名。** 两者预测的对象、量纲和评估数据都不同，0.1667 与 31.6 MPa 不是同一件事的误差。

## 一、两篇论文各自预测什么

**Li、Hu & Shao（2023）**（《Tensile strength estimation of paper sheets made from recycled wood and non-wood fibers using machine learning》）
- 论文目标是估计和预测回收纤维纸页的抗张强度劣化，但模型直接输出的是**无量纲损伤指数 D**（D = (D_s−h)²/a² − (D_h−k)²/b²），输入特征为各回收轮次后的保水值 WRV 和相对结合面积 RBA；抗张强度再由 T = T₀(1−D) 换算得到 [3][5]。
- 因此 **0.1667 是损伤指数 D 的 RMSE，不是以 MPa 计的抗张强度误差**。摘要与 4.3 节写明：曲线拟合模型在训练数据上 RMSE = 0.0278，在测试/预测数据上 RMSE = 0.1667；对照的 LSTM RNN 分别为 0.2445 和 0.2206 [1][3][5]。
- 数据规模很小：对木材与非木材（含芦苇浆等）纤维模拟回收 4 次，在每次回收后测量 WRV、RBA、抗张指数等（例如表 2 中芦苇浆回收 0–4 次抗张指数由 28.14 降至 20.22 Nm/g）[6]。文中的"prediction"是模型对未参与训练的测试数据（后续回收轮次的 D）做出预测，并非在大样本上随机划分的留出集评估 [5]。

**Ayaliew 等（2026）**（《Predicting tensile strength in fiber-reinforced composites using machine learning and deep learning models》）
- 预测对象是**纤维增强复合材料的抗张强度（MPa）**，输入特征包括层数、纤维体积分数、纤维/树脂种类、孔隙率等 [11][12]。
- 31.6 MPa 对应 ANN（MLP）在**独立测试集**上的表现：R² = 0.9975、RMSE = 31.67 MPa、MAE = 25.14 MPa；Stacking（LR）为 31.58 MPa；3.2.6 节将二者合述为"R² ≈ 0.9975、RMSE ≈ 31.6 MPa"，而同一测试集（2000 样本）上 ROM 理论模型的 RMSE 为 312.5 MPa [8][9][12]。摘要中"约 31 MPa"即指此值 [13]。

## 二、为什么不能据此排名

1. **被预测量不同、量纲不同**：一个是无量纲指数 D（须再经 T = T₀(1−D) 才成为强度），另一个是 MPa 绝对值。RMSE 的数值大小与量纲直接相关，因此 0.1667 与 31.6 MPa 不能横向比较 [1][3][5][8][12]。
2. **误差所依据的数据条件不同**：Li 基于 4 次回收的小样本序列、测试点很少 [5][6]；Ayaliew 基于 2000 个测试样本，并做了 5 折交叉验证（ANN 的 CV R² 均值 0.9973、标准差 0.0002）[8][12][15]。二者的样本量、任务难度与变异性不可比。
3. **缺少可比的相对精度指标**：要判断"谁更准"，需在同一量纲下比较相对误差（如 RMSE 占强度均值的比例或 MAPE）。Li 文中未报告抗张强度本身的预测误差；Ayaliew 只给出 RMSE、MAE 与 R²，未给出强度均值 [12]，因此无法把 31.6 MPa 换算成可比的百分比。这一信息缺口无法用现有材料补齐。
4. **能比的只是各自文内的相对结论**：Li 中曲线拟合优于 LSTM RNN（0.1667 vs 0.2206）[5]；Ayaliew 中 ANN/Stacking 远优于 ROM 与 SVR [8][10][12]。这些结论只在各自体系内成立，不能跨文合并成"前者更准"。

**不确定性说明**：Li 的 0.1667 是测试/预测数据上损伤指数 D 的 RMSE，若该文另有抗张强度误差而未在可见文本中报告，本回答无法涵盖；Ayaliew 的"约 31 MPa"是摘要对 31.67 MPa 的取整表述 [9][13]。

**若要做可比评估**：需将 Li 的 D 误差经 T = T₀(1−D) 传播为强度误差（该文未做此换算），或在同一量纲下用相对误差与各自强度均值比较；所需数据两文均未完整给出。
