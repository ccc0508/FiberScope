## 结论

**三种工具的分工（Morais & Curto 2022, *Tissue prediction*）**

- **MLR 与 ANN**：两者都是数据驱动的统计模型，目的是把纤维形态、悬浮性能和纸张结构性能与最终使用性能关联起来，包括 softness HF、softness TS7、tensile index、吸水能力和毛细上升。模型使用实验设计所收集的数据建立，覆盖纤维配比、机械与酶处理、助剂加入以及工业 base tissue 纸等工艺步骤 [1][9]。MLR 中每个加入的自变量在统计上均显著（p<0.05）[9]。
- **3D 纤维模拟器（voxelfiber）**：这是一个基于元胞自动机的开源模拟器，它把每根纤维表示为体素序列，输入参数包括长度/宽度比、纤维柔顺性、纤维壁厚、腔径和分辨率等；它在三维基体中随机沉积纤维，并避免不同纤维之间发生空间重叠，从而生成平面随机网络 [2][4]。该模拟器用于考察纤维对**结构**性能的影响，并输出有效厚度、bulk 和表观孔隙率；这些结构量也可以回代到统计模型中，用来预测功能性能 [2][11]。

**验证样品：不是建模（拟合）时用过的样品**

- 4.3 节的验证使用漂白桉木硫酸盐浆、生物聚合物助剂和工业 base tissue 纸，原文明确说明 “these samples were not used to build the models” [11]。桉木浆按 PFI 500、1000、1500 转、打浆强度 3.33 N/mm 处理，并制备 20 g/m² 各向同性实验室结构，用于结构性能与功能性能测试 [11]。
- 验证展示共涉及六个对象：0、500、1000、1500 PFI 转的桉木浆样品，加入生物聚合物的样品，以及工业 base tissue 纸 [11]。其中后两者的样品标签出自 Figure 7 图注 [11]。
- 3D 模拟器的验证同样使用这批新样品：在四个打浆水平下，将模拟结构与实测结构的厚度、bulk 和表观孔隙率进行对比（0 转：实测 101 μm、4.89 cm³/g、86.37% 对应模拟 99、4.81、86；1500 转：实测 77 μm、3.90、82.89% 对应模拟 76、3.84、82）[11]。

**限制与不确定性**

- “未用于建模”是作者在正文中的声明 [11]。现有收录材料未包含补充材料（Tables S1–S3），因此无法核对训练集的具体样品清单，也无法核对 ANN 是否另有训练/测试划分；ANN 的这一细节在本次检索范围内未取得 [1][9]。
- Table 3 的模拟与实测对比引用原文表格数值，未做独立统计检验；“吻合”是作者的判断 [11]。
- 结论部分指出，MLR 与 ANN 的预测整体“令人满意”，但工业 base tissue 纸的柔软度和毛细上升性能除外 [13]。
- 3D 模拟器使用的纤维尺寸取自这批样品的 MorFi 实测，因而其验证方式是“以实测纤维参数为输入、再与同一批结构的实测结构性能比对” [2][11]。

## 结论

**三种工具分工（Morais & Curto 2022, *Tissue prediction*，PDF 第 1、3、4 页）**

- **MLR 与 ANN**：属于数据驱动统计模型，目的是把纤维形态、悬浮性能（ºSR）以及纸张结构性能（如 bulk、孔隙率）与终端功能性能关联起来：softness HF、softness TS7、tensile index、吸水能力、毛细上升。模型用实验设计收集的数据建立，覆盖纤维配比、磨浆、酶处理与助剂加入等工艺步骤 [1][9]。MLR 的各个自变量在统计上显著（p<0.05）[9]。
- **3D 纤维模拟器（voxelfiber）**：基于元胞自动机的开源源码工具，把每根纤维表示为体素序列，输入长度/宽度比、纤维柔顺性、胞壁厚度、腔径、分辨率等参数，随机沉积生成平面随机纤维网络，并对空间不重叠约束做计算；它用来考察纤维对**结构**性能（有效厚度、bulk、表观孔隙率）的影响，所算出的结构量还可以作为输入，回代统计模型去预测功能性能 [2][11]。

**验证样品：并非建模时用过的样品（作者明确说明）**

- 验证部分（4.3 节，PDF 第 9–10 页）用的是漂白桉木硫酸盐浆、作为助剂的生物聚合物，以及一种工业本色（base）tissue 纸；原文明确写道 “these samples were not used to build the models” [11]。桉木浆另外按 PFI 500、1000、1500 转、打浆强度 3.33 N/mm 处理，并制备 20 g/m² 各向同性实验室结构，用于结构性能与功能性能测试 [11]。即六个验证对象是：0、500、1000、1500 PFI 转样品、加入生物聚合物的样品和工业 base tissue 纸 [11]（据 Figure 7 图注）。
- 3D 模拟器的“展示验证”也是同一批新样品：在四个打浆水平下，把模拟结构与实测结构的厚度、bulk、表观孔隙率对比，结果被认为与实验吻合（如 0 转：实测 101 μm、4.89 cm³/g、86.37%，模拟 99、4.81、86；1500 转：77 μm、3.90、82.89% 对应 76、3.84、82）[11]。
- 需要注意：3D 模拟器所用的**纤维尺寸**来自这批样品的 MorFi 实测，所以它属于“以实测纤维参数为输入、再与同一批结构的实测结构性能比对”，与统计模型的样品独立性不是同一种含义 [2][11]。

**限制与不确定性**

- 上述“未用于建模”是作者在正文中的声明 [11]；八篇收录文献中未见其补充材料（Tables S1–S3），无法核对训练集的具体样本清单与划分方式，也无法核对 ANN 是否另有训练/测试划分（ANN 细节在此检索范围内未取得 [1][9]）。
- Table 3 的对比数值为原文表格数值，未另做统计检验；文中判断“吻合”的依据是作者叙述，不是独立误差分析 [11]。
- 结论部分也指出，工业 base tissue 纸的柔软度与毛细上升模型例外，预测并不理想 [13]。

依据文献：Morais, Carta, Amaral, Curto (2022) *Tissue prediction*（01_Morais_2022_Tissue_prediction.pdf），摘要 p.1、2.2 节 p.3、3.3 节 p.4、4.1 节 p.4、4.3 节及 Table 3 p.9–10、结论 p.10–11。
