# FSX-003

只根据我提供的数据计算，不查论文：A的抗张指数为40 N·m/g，B未测，C为50 N·m/g。请输出已测样本均值、参与计算的样本数和缺失数，并说明把B当0计算会得到多少，以及为什么这个处理不合适。

只根据你提供的数据计算，不查论文：

- **已测样本**：A = 40 N·m/g，C = 50 N·m/g
- **已测样本均值**：(40 + 50) / 2 = **45 N·m/g**
- **参与计算的样本数**：**2**（A、C）
- **缺失数**：**1**（B）

**如果将 B 当作 0 计算**：三个数的平均值为 (40 + 0 + 50) / 3 = **30 N·m/g**。

**为什么这种处理不合适**：
1. 把“未测”当作“实测值为 0”，相当于假设 B 的抗张指数确实为零；但这一信息在你的数据中并不存在，未测不等于测得为零。
2. 这个例子显示，对缺失值填 0 会使均值从 45 降到 30 N·m/g，即偏低 15 N·m/g，相对偏低约 33%。
3. 由于该均值被用于后续比较或统计计算，这种偏差会传递到比较或统计结果中；仅凭给定数据无法判断偏差的方向和幅度在其他情境下是否相同，但它源于一个未经证实的假设。
4. 更合适的做法是：报告基于 2 个已测样本的均值 45 N·m/g，并注明 n=2、缺失 1 个（B）；或补测 B 后再计算。若确需估计，应明确说明缺失值处理方法及其假设，并报告相应不确定性，而不是默认置零。

以上均为基于给定数值的算术计算示例，不含任何论文证据；未提供 B 的真实值和测量条件，因此无法确定包含 B 的真实均值。
