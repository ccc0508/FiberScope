# 表 3 原文数据整理

本目录整理 Ferdous 等（2021）《Non-Wood Fibers: Relationships of Fiber Properties with Pulp Properties》的 Table 3，用作后续文献提取流程的第一份对照样例。

整理结果包含 **22 种原料、12 个数值列、264 个原文数值**：132 个原料形态数值，以及 132 个纸张性能数值。后者对应 22 种原料的未打浆和打浆后两种状态。44 组状态不代表 44 次独立重复实验。

## 文件用途

| 文件 | 内容 | 使用方式 |
| --- | --- | --- |
| `表3标准数据.xlsx` | 中文表头、原文名称、全部数值、来源页码、审核状态和备注；附字段解释和原文疑点 | 人工对照 PDF 核查；审核状态和备注可填写 |
| `table3_wide.csv` | 22 行，每种原料一行，12 个数值列保留论文精度 | 查看表格全貌、与自动提取的宽表比较 |
| `table3_measurements.csv` | 264 行，每个指标数值一行，含单位、测量状态、原文表头和数值位置 | 作为结构化提取的逐项比较基准 |
| `metadata.json` | 论文信息、PDF 指纹、字段字典、核对方法、疑点与数据使用边界 | 固定来源版本，解释字段和核对范围 |

两个 CSV 使用 UTF-8 BOM，便于在 Windows Excel 中打开。数值列为数值文本，未添加单位后缀；程序读取时可转换为数值。`raw_value` 保留原文数字写法，例如 `2.0`。

Excel 的审核状态与备注是独立填写区域。修改它们不会同步改写 CSV 或 JSON；本轮也未实现网站审核接口。

## 字段含义

表 3 的六个形态数值属于**原料形态测量**，不等于打浆前后各自测得的纸浆形态。整理时只保留一份原料形态数值，未复制成两组测量。

| 字段 | 中文含义 | 表头单位 | 测量对象或状态 |
| --- | --- | --- | --- |
| `fiber_length_mm` | 纤维长度 | mm | 原料形态 |
| `fiber_width_um` | 纤维宽度 | μm | 原料形态 |
| `wall_thickness_um` | 细胞壁厚度 | μm | 原料形态 |
| `slender_ratio` | 长宽比 | 未标注 | 原料形态 |
| `runkel_ratio` | Runkel 比 | 未标注 | 原料形态 |
| `flexibility_coefficient` | 柔性系数 | 未标注 | 原料形态 |
| `tensile_index_unrefined_Nm_g` | 抗张指数 | N·m/g | 未打浆 |
| `tensile_index_refined_Nm_g` | 抗张指数 | N·m/g | 打浆后 |
| `burst_index_unrefined_kPam2_g` | 耐破指数 | kPa·m²/g | 未打浆 |
| `burst_index_refined_kPam2_g` | 耐破指数 | kPa·m²/g | 打浆后 |
| `tear_index_unrefined_mNm2_g` | 撕裂指数 | mN·m²/g | 未打浆 |
| `tear_index_refined_mNm2_g` | 撕裂指数 | mN·m²/g | 打浆后 |

长表使用 `metric` 与 `measurement_state` 分别保存指标和状态：`raw_material` 为原料形态，`unrefined` 为未打浆，`refined` 为打浆后。未标注单位的三个字段保持空单位，并用 `unit_status=not_reported_in_header` 明确表示，不补百分号或自行缩放。

`sample_id` 是本次整理的文献原料记录编号，只在该论文表 3 范围内有意义。中文名称为辅助译名，物种识别和跨表关联应回到原文名称及方法部分，不直接连接现有实验样本编号。

`source_bbox_pt` 是原文数值的 `[x0, top, x1, bottom]`，以该 PDF 页左上角为参照、单位为点。它定位的是数值文字，不是整行或表头；审核时需要连同表头及行名查看。

## 已完成的核对

## 后续使用

可以用这份数据检验自动提取是否漏行、漏指标、数值错位、单位错配，或者混淆打浆状态。比较时以 `(sample_id, metric, measurement_state)` 为键，并核查原文原料名称、单位、表格来源；不能只比较总数。

这是一张表的初始提取基准，尚未运行大模型提取评测，也不足以证明对其他论文的提取效果。后续需要加入不同表头、正文叙述和缺失值样例。

Table 3 未列出每种原料具体的打浆度、时间、转数，也没有逐次重复观测或标准差；不能把 `refined` 当成所有原料均采用同一打浆条件，不能补猜缺失条件。建模前还需要核对实验条件、原料测量与纸浆测量的区别，以及不同论文的可比性。

本轮仅新增这份文献整理样例，未写入实验 PostgreSQL 数据库、未修改 `data/dataset`，未训练模型。
