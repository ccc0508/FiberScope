# FiberScope 分析平台前端

Vue 3 + TypeScript + Vite。已实现六个实验数据页面、文献问答和文献数据提取审核，共八个页面。实验数据保持只读。

## 启动

先在项目根目录启动后端，读取现有原数据库连接配置：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --env-file backend/.env --host 127.0.0.1 --port 8000
```

在另一个终端启动前端：

```powershell
cd frontend
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/>。Vite将 `/api` 代理到本机8000端口。
前端没有数据库账号、密码或伪造的演示数据；后端不可用时显示错误和重试按钮。

```powershell
npm run build
npm run preview
```

build先执行严格TypeScript检查，再生成dist；preview在4173端口预览构建结果，也代理本机后端。
部署到其他服务器时，需要为 `/api` 配置反向代理；dist本身不包含后端服务。

## 功能与数据口径

- 全库统计：物理样本、核心展示点、循环观测、已收录指标。
- 样本组成：点击类型筛选表格，可再次点击取消；统计图保持全库口径。
- 记录配对率：fiber-paper视图行数 / 样本数，不代表所有指标非空。
- 表格：编码/名称搜索、类型筛选、10/25/50条分页，按后端固定编码顺序显示。
- URL保存q/type/page/size，刷新后保留筛选和分页。
- 点击样本编码打开详情抽屉，显示原料比例、打浆条件、Excel文件、工作表及行号。
- NULL显示为“—”；零仍显示0；复配条件按针叶木/阔叶木分别列出。
- 请求取消和超时处理；加载骨架、空结果、错误编号和重试；手机端折叠左侧导航和表格横向滚动。

## 设计参考

参考 [Metabase官方探索教程](https://www.metabase.com/learn/metabase-basics/getting-started/explore-data)
中的卡片分组、图表筛选、数据表格与逐条查看的交互方式。
固定导航放在左侧，采用自有FiberScope标识和实现，没有复制Metabase源码或品牌资产。

视觉为「实验记录本」风格：暖白纸页底色、墨色正文、深青色强调（`--signal`），
标题用宋体（Noto Serif SC），读数和编码用等宽字体（IBM Plex Mono），字体均随前端打包、不依赖外网。
三种原料固定配色：针叶木浆琥珀 `#8a5604`、阔叶木浆绿 `#127a3a`、针阔复配紫 `#7a3f98`，
在纸色底上对比度均不低于5:1；颜色变量在 `style.css` 的 `:root`，图表脚本从 `palette.ts` 引用。

验证结果见 [前端验收记录](../docs/FRONTEND_VALIDATION.md)。

## 打浆分析

访问 `/beating`。原料可选全部、针叶木、阔叶木；支持打浆度及接口目录中21项核心指标。原料、指标、目标打浆度（`target`，20—85 °SR，默认45）和打浆度区间（`sr=下限-上限`）保存在URL中。

- 打浆度区间：筛选条附当前原料的打浆度分布直方图。区间只筛选明细表、样本读数和计数；曲线保留全部实测点，区间外的点淡化显示；KPI按完整曲线计算，不受区间影响。

- 打浆度：顶部显示两种原料首次达到目标打浆度所需的转数及相差转数，曲线上画目标线和交点。转数由相邻两个实测点线性插值估算并取整到百转，页面上注明为估算。
- 其他指标：显示每种原料首个与末个有效观测的数值及变化百分比。
- 曲线按打浆转数排序，缺失值断开，零值保留，不作拟合。悬停按实测转数逐个读数；点击或Tab聚焦数据点在「样本读数」中选中，Enter/空格打开样本来源抽屉。
- 样本读数：打浆度指标下显示距目标还差多少°SR、按本原料曲线估算约需再打浆多少转（插值、取整到百转）；对比同转数下的另一种原料：有实测用实测值，没有则插值并注明，超出实测范围不外推。曲线上选中点旁标出数值。
- 明细表按原料分组、组内按转数升序，数值保留4位小数；点击样本编码或「查看详情」打开来源抽屉。
- 「较另一种原料（同转数）」列为本样本减去另一种原料在同一转数下的值；另一种原料无实测时按插值比较并以“≈”标出，超出其实测范围显示“—”。
- 可勾选样本并导出CSV：有勾选时只导出勾选行，否则导出当前筛选结果。CSV带BOM，数值原样导出不取整，并注明另一种原料取实测还是插值。
- 页头的纤维显微图是AI生成的示意图（非实测），仅作装饰；不支持WebGL时不显示，开启「减少动态效果」时停止漂移。

## 复配分析

访问 `/blends`，默认抗张指数，可切换21项核心指标。横轴为针叶木比例0—100%，阔叶木比例为其余部分。11个展示点包括9个复配样本及2个复用的纯浆端点；明细显示两种原料的打浆转数和打浆度。点击图表或表格可追溯样本来源；筛选保存在URL中。

## 纤维—纸张关联

访问 `/association`，默认长度加权纤维长度与抗张指数。横轴支持12项纤维特性，纵轴支持9项纸张指标；类型和指标选择保存在URL中。每个点代表一个唯一样本，点击或键盘Enter/空格打开来源抽屉。配对明细保留缺失值，统计仅使用成对有限数值，不补零。

Pearson r按当前筛选及样本类型分别计算。少于3对有效数据或任一指标无变化时不显示系数；合并类型可能受实验条件影响，不提供因果或显著性结论。运行 `npm test` 检查相关系数及坐标范围计算。

## 再生纸浆循环

访问 `/recycled`，选择14个数据块及25项指标，默认G01和长度加权纤维长度；筛选保存在URL中。每个点为同一数据块、同一循环内非空指标值的平均值。全库47个循环汇总点、131条原始观测，独立于61个核心样本。

点击曲线点、按Enter/空格或点击“查看原始观测”，可查看重复序号、当前指标原始值、Excel文件、工作表和源行。弹窗支持Escape关闭。记录总数和指标有效值数量分别展示；缺失值不补零，曲线不跨缺失点连接。处理条件未确认时明确标注，不推断名称。手机端图表和表格各自横向滚动。

## 数据来源

访问 `/sources`。9个已入库来源文件对应309条来源行：178条核心实验来源行和131条再生纸浆观测。按文件、工作表、版本和源行合并核心实验的多项用途，保留两个原料组分的区别。来源行数不是样本数，也不是原始Excel全部行数。

可点击文件卡片或筛选器选择文件，按核心实验/再生纸浆筛选，输入样本编号、数据块、文件名、源行或空格分隔的组合词搜索。每页25条，筛选和页码保存在URL。来源详情展示实验编号、组分、指标类别、关联样本；再生纸浆展示25项原始指标和所属循环，并可进入该数据块的趋势页面。未关联样本的来源不推断对应关系。

样本详情中可直接进入合并后的来源行。页面集中解释61个核心样本、63个实验展示点、131条原始观测和47个循环汇总点的口径；不展示质量复核项。`npm test`同时覆盖来源合并、排序、检索及空值/零值保留。

## 文献问答

访问 `/literature`。展示已导入文献，支持独立单轮问题、校验后的回答及引用、原文片段和PDF跳页。提交后轮询服务端记录，刷新自动恢复最近一次问答；历史支持搜索、分页、重新提问及JSONL导出，评价支持修改和问题标签。未启用、空库、忙碌、超时、服务失败和保存失败均有明确反馈。不渲染模型HTML，也不把模型密钥发送到前端。真实文献库和模型配置需要独立部署，详见[文献问答接入说明](../docs/LITERATURE_QA.md)及[记录说明](../docs/QA_HISTORY.md)。

## 文献数据提取与审核

访问 `/literature-data` 或左侧“科研助手 → 文献数据”。默认整篇自动识别，上传PDF后模型逐页寻找相关表格和正文数值；也可切换指定表格。页面显示扫描进度、发现理由和未完成说明，按来源、原料及审核状态筛选。点击候选指标，自动切换原文页并定位数值及上下文。支持任务搜索、分页、刷新恢复、失败重提取。

审核支持原料、指标、测量状态、数值和单位修改，以及补充带来源的实验条件；确认抄录与建模适用性分别标记。保存后可查看完整版本历史，原始提取快照不覆盖。已确认数据可导出CSV或JSONL，未审核或驳回记录不进入该导出。所有访问者可查看、修改文献审核和导出，清除Cookie或通过分享链接访问也可审核；并发保存检查版本，旧版本返回409要求重新读取。没有实名专家审核。详见[使用说明](../docs/LITERATURE_EXTRACTION.md)和[审核验证记录](../docs/LITERATURE_REVIEW_VALIDATION.md)。
