# 主命中候选统一补全

2026-10-31。将MinerU科学小节补全和正文—表格关联改为同一候选收集、去重和预算分配流程。表格行检索继续保留，113块原文、20条行向量、10条关联及所有历史验证材料不改写。本轮不切换网站默认配置，不调用新的答题或评分服务。

后续启用：当前MinerU组合配置已按用户要求加入候选重排，发生在选择主命中与统一补全之前。无重排对照配置完整保留；见[重排启用与验证](QA_MINERU_UNIFIED_RERANK_20261031.md)。

## 最终流程

问题向量 → 正文/行检索合并 → 筛选最多8个主命中 → 仅从主命中收集补全候选 → 一次预算分配 → 最终证据。

候选来源：

1. 正文、表格、公式主命中所归属的可靠小节中的科学内容。元数据、参考文献、不确定块不能通过该路径进入补全。
2. 正文或表格主命中已有的明确正文—表格关联，允许跨小节或跨页。没有独立模型判断每块是否必要；关联只提供候选。
3. 缺少可靠小节的正文主命中所对应的明确同页续句。缺少可靠小节的表格和公式不启动邻块兜底。

同一来源可以同时具有“小节”和“明确关联”两个依据，仍只保留一次。补入的段落、表格、公式不会再次收集它们的小节或关联；表格自身只有作为主命中时，才能主动带入其小节解释。

小节候选收集不再另行扫描已补入段落的表号；表号关联统一由已封存的角色受限关联目录提供。每个明确关联的起点都必须是原始主命中。

## 预算和优先级

- 先完整预留全部主命中，保留表格、公式的独立锚点、完整源文字和页码。
- 证据组按最早主命中的排名处理；每组先考虑明确关联候选，再考虑同小节候选和续句候选，同级按与本组主命中的块序距离等确定顺序。同小节多个正文主命中合并后，也一起排列它们的关联候选。
- 每个主命中最多收集2个非主命中的明确关联目标；每题全局最多8个不同关联目标。这是候选上限，不能解释为最终必定补入的数量。
- 所有候选共用单条8000、全部24000字符预算。整块放不下就省略，不截断表格或公式，也不另开一个后处理证据条目把同一候选加回来。
- 全局去重同时覆盖主命中、小节候选和关联候选。多个依据会保留在诊断中，不重复消耗来源空间。

无可靠小节的正文、表格仍可用它们自身的明确关联。例如正文命中直接提到另一个小节的表格时，可以在同一次组装中补入完整表格；这张新补入的表格不会再带出另一个小节。

## 实现和版本

新增`backend/literature_rag/application/unified_context.py`，收集每个主命中的候选和依据，然后调用一次受预算限制的组装器。MinerU路径不再调用`append_related_tables`后处理；该旧函数继续服务原有同页补全实验，传入科学小节目录时会拒绝叠加。

版本：不启用行检索时为`unified-scientific-context-v4`，启用时为`unified-scientific-table-context-v3`。配置入口仍是`body_section`；既有私有MinerU候选配置不需要重新建索引。默认PyMuPDF网站配置及服务器未切换。

诊断新增单次组装、候选起点、候选依据、明确关联候选、最终包含的关联候选与省略原因。新版本的`selected_explicit_link_chunk_occurrences`统计进入证据的明确关联候选，可能同时具有小节依据；不能与旧版“第二阶段新增8次”直接比较。

旧版8次额外关联补入发生在第9、11、14、16、17、24、29、31题。逐项核对发现：这些说明正文原本已经属于某个主命中的小节候选，但放回原证据组会达到8,253或8,389字符，超过8000限制。小节阶段跳过后，旧后处理通过另外一个证据条目加回，仍满足各条及总字符上限，却形成了第二个补全入口。新版本不再这样处理，本轮这8个“题目—来源块”组合均未进入最终证据。

本次也统一了候选优先级，并非纯删除这8次补入：全部32题的补充来源相对上轮共减少21个、增加13个“题目—块”组合。这是最终证据选择变化，原数据库和索引中的块没有删除。

本轮新增解析、Embedding、重排、回答和评分调用均为0；只有检索/组装验证，没有新的答题质量分数，不能声称得分提高。
