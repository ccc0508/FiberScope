# 图片发现与查看

检索完成后，除证据块原有图片外，扫描证据正文中的显式 Figure/Fig./图编号，在同一文献内匹配图片标签并附带图片入口。仍遵守每次图片数量与字节预算。仅用户问题提到图号、不在证据正文中出现时，不自动给文本证据挂图。

模型可见的图片入口统一使用 `asset_id`；底层资产文件及历史轨迹的 `id` 保持兼容，由输出投影转换。

新增 `find_figure(document_id, figure_number, reason, offset=0)`，每页最多20个入口。返回明确匹配项及无编号候选；后者标记 `unconfirmed_number`，不按页序猜测图号。编号须为 `3`、`3.1` 等，不含“图”前缀。发现工具不提供像素，不注册已读图引用；必须继续调用 `view_image` 才能读图并取得图片引用。该工具沿用 Agent 总工具次数、时间和上下文预算。

MinerU 漏失图号时，自动关联无法确定目标。兜底会暴露同文献无编号候选，让模型核对，不能保证图号恢复或模型必然选图正确；拆分子图也不因同页而强行合并。

验证：33项相关单元测试通过；以八篇论文索引中的 CLSM 论文查找图3，返回包括第6页抗张强度、耐破度的编号待确认候选，并成功读取耐破度原图（43006字节）。未重跑付费模型答题或评分。
