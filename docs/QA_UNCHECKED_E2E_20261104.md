# 关闭审校内容校验：32题端到端实验

## 实验目的

从用户问题开始重新运行检索、初答和审校，观察模型建议不受程序内容校验拦截时的最终答案。不是重放历史修改建议，也不是将旧评分分配给新答案。

## 固定与变化

- 沿用32道核心题、同一论文和现有MinerU/Qwen3-VL索引快照。
- 查询改写重新调用；原问题与改写问题分别检索、合并去重，由BGE reranker按原问题排序，最多8个主命中，再进行现有正文小节、表格和图片补全。
- 初答、审校使用DeepSeek Flash High。每题独立进程，不向答题/审校模型提供标准答案、评分或其他题目的对话。
- 审校提示词沿用当前统一核查版本；单轮输出上限65536，单轮请求超时300秒，最多两轮。保留最多一次、两个动作的同文献补查及数值区域交叉核对。
- 初答的原有引用格式检查及其最多一次重试保留。
- 审校返回仅要求可解析JSON及可执行的issues数组；不检查原句匹配、原文匹配、核查标签、核查记录完整性、科学判断、引用支持或修订后的引用格式。
- 直接按claim_index执行replacement_claims。不存在的索引、不可执行的替换结构记录为执行异常；相同目标重复修改按最后一项执行。模型内容不做格式归一化，不补写引用，也不调用额外的核查元数据补全。
- 修订后的回答保留模型输出；不存在的引用标识不伪造来源。原始审校JSON、执行事件、每轮前后答案、最终证据及模型用量分别保存。
- 每题进程外层超时1000秒，用于覆盖新检索、初答及最多两轮审校；不是每个模型请求均可运行1000秒。

## 隔离和复现

实验代码仅位于`scripts/qa_unchecked_e2e_worker.py`，运行时复制到私有实验目录，替换本进程内的审校执行入口。没有修改网站默认审校行为、线上服务或私有配置。

`manifest.json`保存运行源码哈希、库文件哈希、原有配置探测和实验说明。配置探测中的审校校验说明来自常规运行时；实验实际行为由上述独立worker覆盖，不能将常规配置描述理解为本次仍执行内容校验。

运行入口：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/evaluate_unchecked_e2e_20261104.py prepare
.\.venv\Scripts\python.exe -X utf8 scripts/evaluate_unchecked_e2e_20261104.py run
.\.venv\Scripts\python.exe -X utf8 scripts/grade_unchecked_e2e_20261104.py prepare
.\.venv\Scripts\python.exe -X utf8 scripts/grade_unchecked_e2e_20261104.py grade
.\.venv\Scripts\python.exe -X utf8 scripts/grade_unchecked_e2e_20261104.py inspection
```

已存在的实验不可重新prepare。已完成的答案不重跑、不择优；被中断的付费请求需要先检查记录。

## 评分和解释边界

Jev继续使用同一政策，逐题独立评分，仅对无效/失败评分最多尝试三次，首次有效评分即保留。最终由Codex逐题核对论文及实际引用，另行记录调整前后值和依据；不覆盖Jev原始输出。

统计必答要点、事实支持、单引有效性、引用组完整性、边界及五项全部达标题数，不增加未经约定的加权综合总分。无效Jev评分与回答失败不是同一回事。

此前最新32题结果是固定初答的审校实验；本次检索、初答、审校均重新生成。两者可作为系统表现参考，但分差不能全部归因于关闭校验。只有一篇论文、32道重复使用的开发题，一次运行不能证明稳定性或新论文泛化能力。

结论限于本次观测：执行阻力消除且成绩较参考结果更好，但新检索和新初答也发生变化，不能据此单独证明关闭校验带来多少提升，或证明应永久取消所有校验。下一步可用这次原始审校输出离线对照现有校验，定位哪些门槛确实会挡住正确修改，无需重新花费答题费用。
