# 回答完整性与证据边界：固定证据A/B

2026-10-31。本轮只检验通用回答要求的变化，保持生成模型、输出结构、引用校验与最多两次格式纠正不变；不启用重排，不调整解析或检索。

## 产品实现

新增可选`RAG_ANSWER_GUIDANCE_ENABLED`，默认false。关闭时逐字返回原`SYSTEM_PROMPT`；开启时追加通用指引，要求直接回应子问题、绑定数值与单位条件、在证据充分时给出数值例子或反例、保留“可能”等不确定性、区分可支持的推断和未知、明确缺失信息的范围，并让每条引用覆盖相应陈述。

指引不包含任何题号、论文专属数值或标准答案，不强迫每题追加限制套话，不把“检索没有找到”当成整篇不存在，也不要求单条引用证明整篇内容缺失。纯范围说明应与被引片段实际提供的内容绑定。所有实质回答仍放在展示用的claims中，不新增思考过程、检查表或输出字段。

两类生成适配器均支持该开关，模型、调用次数和JSON结构不变。配置快照记录指引版本与文本指纹，不记录密钥。网站默认开关和配置本轮不切换。

## 固定证据比较

预先指定原85块、无重排版本第1轮已保存的32组最终证据，完整保留每组原文字、原顺序、引用编号、文件名、页码与来源映射。选择来源发生在本轮A/B生成之前，不按新结果挑选证据。

两版各重新生成32份回答；主对照是本次新生成的control，不是只拿一次历史答案比较。两版每题独立进程，近同时接收同一问题与同一证据，提交顺序按题交替；不附历史回答或旧分。原有生成器和引用校验器照常执行，格式或引用不合格仍最多纠正一次。拒答与失败原样保留，不重做以追求更高分。

此实验绕过查询向量、检索、重排与上下文重新补全，不新增Embedding或重排请求。输入仅含问题、冻结程序路径及封存证据；模型看不到参考答案、评分标准或旧回答。每份输出记录实际生成输入证据指纹，必须与同题两版及封存来源完全相同。

## 评测与解释范围

仅用Jev原五维协议对两版新回答评分，材料独立组装、不附对照臂回答或旧评分。沿用首个有效、最多三次，失败和无效请求全部计费用；不新增Luna/DSH评分。缺失不记零，不计算加权总分；使用共同有效题比较并披露全部32题。

检查必答要点与边界，同时检查事实支持、引用有效、引用组完整、拒答数量、耗时与用量；不能用变啰嗦、无依据的限制或过度拒答换取要点分。Jev存在边界判断误差，特别是既往第11题曾可能宽评；原判保留，报告明确限制。

固定证据A/B只检验生成环节；即使本轮改善，也不能声称完整检索流程已改善或新论文泛化。若值得保留，后续另行验证完整流程与重复稳定性。
