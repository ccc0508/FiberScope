# 固定初稿、固定证据的复核对照

## 修改内容

`backend/literature_rag/application/agent_loop.py`：初稿指令增加直接回答、只补必要条件/限制、不扩展整篇论文；复核改为`focused-evidence-review-v1`，检查数值映射、趋势、因果、排名、样本量及外推，要求无依据的可选内容删除、必要缺口明确说明，最后整理引用。一次整答复核、调用预算和工具不变，没有新增模型调用或程序内容拦截。运行状态保存review_version。

## 实验设计

- 重点题15、24、25、28、31；对照题4、26、27、29。这四题上一轮最终答案全部通过，并不代表其复核前初稿没有缺陷。
- 固定来源为`agent-search2-20261105`中保存的draft，不用上一轮final answer代替，也不重新生成初稿或检索。
- 每题旧/新复核各一次、独立API请求、交替先后顺序；使用相同问题、历史可见对话、初稿、实际已送达证据、已查看图像。图像从原资产恢复并核对payload哈希；不加入未看图片，也不补回历史隐藏推理链。
- 双方均DeepSeek Flash、thinking disabled、无reasoning_effort、8192输出Token，逐题相同超时（沿用该题旧复核请求的剩余预算）。只有末尾复核指令不同；历史系统指令不变。
- 新的初稿生成指令已经修改，但不属于此次固定初稿测试范围。历史初稿来自推理模式，不能将本轮结果直接当作非推理模式完整端到端成绩。
- 18次复核均完成，无截断，不择优或补跑回答。Jev采用原规则；旧31、新15及新31未产生有效评分，Codex补评，并对其他题对照原文校准。原始Jev输出保留。

## 结论

这次修改部分实现了精简，但没有解决主要纠错问题。新增规则并不保证模型执行，尤其会把要求删除的内容改成“可能”继续保留。保留首次结果供后续分析，不宣称优化完成或稳定提升，不据此更新原32题总分。服务器未部署本轮指令。

后续应优先针对已有输入验证“删除无依据扩写”和“保持引用编号身份”，而不是继续叠加更长指令。此建议尚未实施。
