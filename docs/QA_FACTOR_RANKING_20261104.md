# 因素强弱与贡献排名的条件核查

新增可选`v2_ranking / bounded-corrective-review-v2.9-ranking`，继承v2_measurement。默认仍为v1，未部署服务器。

问题或回答出现“贡献最大、最重要、最直接、影响更大”等明确比较信号时，程序才加入排名核查指引，复用现有审校请求。每轮最多选择3条排名陈述，超出部分记录ranking_budget_unchecked，不默认完整；问题本身提出排名但回答未给排名时也检查是否说明无法确定。普通关系与普通数值大小比较不因此触发。规则不使用题号，是启发式匹配，仍可能漏掉含蓄表达或误触发。

触发后复用requirements中的R81记录证据、比较口径和回答边界。核查区分相关性、预测重要性、因果贡献及作者定性解释；关系成立不等于贡献最大，最强相关不能直接称最大因果贡献。充分支持的排名保留并限定条件，作者观点应归属作者；没有依据时删除无根据的优先表述，并在最终回答明确无法据现有证据确定最大贡献。内部审校理由不能代替最终回答。没有新增输出对象或额外模型调用，模型预算不变。

程序检查R81记录存在、来源及修改绑定，语义仍由同一模型判断；有记录不证明判断正确。所谓“最多3条”限制新增详细排名任务，不删除原有审校要求或上下文，因此不能据此保证总Token消耗很小。

## 验证方案

第24题旧版v2_measurement与新版v2_ranking各2次独立审校，同一冻结草稿、MinerU/Qwen证据、原图和文献库。每轮旧/新各一次，输入不提供标准答案。失败不自动补到成功。结果保存在`.rag-data/evaluations/ranking-20261104`。

另有三个明确标注的合成对照：普通正相关、普通长度数值比较、同实验支持的Pearson相关强度排名且声明不代表因果贡献。合成对照不计入32题成绩。未调用Jev或Luna，不产生新整套评分。

这一轮仍有引句不匹配、原句关系检查缺失、完整句位置/结果列表缺失等错误；分子层面还保留了柔顺性、可及性和WRV的并列结果表述。指定排名修好不代表整题事实或全流程全部通过。新版第二次与旧版第一次的completion_tokens和reasoning_tokens均达到32768，未获得可应用的审校输出。未额外补跑到成功。

三项合成对照均保持原答案：普通关系、普通数值比较未触发排名核查；有依据的Pearson相关性排名触发后保留，不被误改成“无法判断”。对应Token为4510、4539、6765。该小规模对照不证明所有表达均能正确路由。

## 成本与结论

旧版两次平均43520 Token、167.673秒；新版平均42991.5 Token、157.471秒。新版单次输入由12997增加到13364，即367 Token（约2.82%）；总Token均值约低1.21%，但两组各有一次截断，样本很小且推理量波动，不能认定新规则降低成本或证明无额外成本。新增核查没有增加调用数：四次第24题和三项对照共7次审校、0次补查；累计188837 Token，货币费用未知。

206项相关测试通过。最终结论：新增规则能识别并修复第24题的指定排名缺陷，但仅1/2次成功，尚不稳定；当前主要运行障碍仍包括长审校输出耗尽预算和其他辅助诊断错误。保留为可选实验，不改默认版本，不宣称第24题已经完全解决。
