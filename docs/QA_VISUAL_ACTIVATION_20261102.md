# 本机文献问答默认启用图片检索与DeepSeek原图输入

2026-11-02。原有图片链路和11组图像向量已经存在于MinerU候选库；本次复用它们，将本机网站默认配置从旧PyMuPDF/BGE文字库切换到图文库，并按实际默认配置完成HTTP问答、原图读取和历史页面检查。

## 当前流程

原问题与改写问题分别使用Qwen3-VL-Embedding向量化，同时召回文字块、表格行和原图向量。图像命中映射回原图注/表格父块，与文字候选合并去重，仍由BGE按原问题做文字重排。最多8个主命中，之后按既有小节和表格关联统一补全，保留8000/24000字符预算。

最终证据关联的原图以真实PNG图片数据交给DeepSeek Flash High；最多4张、总计12 MiB。问题明确指定的图号优先。原图包括图表内部的像素信息，模型不能只凭图注声称读取了图像。引用卡片显示原图，历史独立缓存所有实际输入图片。
