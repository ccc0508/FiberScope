## 初次校验、补评与恢复

32次初始请求均收到API响应，其中16份评分首次通过程序校验，16份因评分结构或依据校验未通过而保留为`invalid_scorecard`。随后进行了8次协议补评和3次追加补评，累计43次实际请求。不是连续挑选更高分的回答；已经有效的评分不重新调用替换。

最终32份评分由20份直接通过的响应和12份零调用兼容复核视图组成。43次付费响应中，20份直接通过、23份保留原始拒收状态；零调用视图引用其中可恢复的原响应，不另算模型请求。原始失败记录和所有补评费用均保留。

恢复主要涉及两类兼容问题：

- 8题的模型把检索状态写为`complete：具体说明`等形式。程序只拆分明确给出的枚举和说明，保留原始完整文本与前后轨迹，不猜测缺失标签，不改变裁判所选状态。
- 第025、026题的混合陈述同时提交了科学事实引文和当次检索范围说明。此前程序错误地只允许纯范围陈述附带范围说明，导致拒收。修正后仍分别校验科学引文和完整的实际检索范围；范围说明不能单独证明科学事实。两题均从已保存的第一轮补评响应恢复，未新增调用，也未改写模型分数。

其余结构复核只整理诊断编号或结构。原始模型响应、实质分值、事实/范围标签、引用及依据原文均保持不变。最后一次兼容复核由30份恢复到32份；此前29份、30份阶段汇总继续保存。代码修复已通过本机针对性检查和服务器193项相关自动检查；最终公开统计又在本机与服务器独立复算，结果一致。

另抽看两处要点分歧，说明不能把任一裁判当作最终答案：

- **PFI2-007 P3：Luna为1、Jev为0。** 原回答分别定义峰强度法、峰面积法并给出计算口径。共同规则明确这种表达不必再照抄“不能混用”，因此这里Luna的判断更符合v3。
- **PFI2-023 P3：Luna为1、Jev为0.5。** PDF摘要与第10页3.4节确有0.888和0.912的冲突。回答保留两值并标出摘要，但没有明确提醒“不一致”。按v3对冲突关系须在回答中表达的要求，这里Jev的部分分更稳妥。
