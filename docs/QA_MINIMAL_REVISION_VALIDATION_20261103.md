# 最小修订方案：五题三次配对验证

2026-11-03。结论：测量边界与因素排名有改善，但第31题漏检、第23题引用修复不稳定、第32题证据预算退步；不采纳整套v3为默认版本。此次是定点开发验证，不是32题重测。

## 实验方式

第18、24、31题检验目标问题，第23、32题检验回归。旧版v2.1与实验版v3各运行3次，每次5题，共30份最终答案。顺序预先固定为v2/v3、v3/v2、v2/v3；每次请求独立上下文，无历史对话。三次均计入，不筛选最好答案。

固定2026-11-02的初始回答、初始证据、候选缓存与MinerU/Qwen图文库，只重放审校和有限补查。DeepSeek Flash/High、32768输出上限、最多两轮审校、一次补查轮次、8000/24000字符预算、重排模型与评分政策不变。运行前保存源码哈希、输入哈希和完整源码副本；未向回答模型提供标准答案。

v3新增通用的测量边界、比较证据和最小修改指引，以及每项拟议修改的`revision_checks`。这是同一个模型在同一次请求中自检，不是额外独立模型或新一轮语义验证。记录缺失/重复/不支持时拒绝该项修改；已有来源位置和引用格式检查仍生效。v1默认配置未改，未部署服务器。

## 具体问题及归因

### 第18题：限定语有效

v3三次都在面积口径句中加入“并非绝对氢键数量/分子数/含量”，引用原有[3]相对面积计算依据。没有增加额外检索。这说明在这些固定输入上，明确测量量和推断量的关系检查有效，不证明对所有问题均有效。

### 第24题：排名修好，但有改错句的风险

v3三次都删除“联系最直接”，改为没有独立定量排序，不能判断哪个贡献最大。

然而第三次v3将针对原始零基索引4（形态描述）的修复标成5，针对索引6（氢键总量）的修复标成7。程序应用后，零距/纤维强度句和湿纸幅强度句被替换，原错误仍在，还增加了重复内容。辅助检查已记录`claim_check_edit_targets_different_claim`，但现有故障隔离仅将诊断标为不完整，没有阻止来源位置合规的独立修改；同次自检又错误地将修改判为支持。

第24题的“排名通过”不能掩盖这一新问题。部分其他回答还把柔顺性、可及性、WRV一起写成氢键/CI降低的结果，超过原文语法直接支持的范围，已在来源核对备注中保留。

### 第31题：必查句识别漏掉原有因果链

冻结初始草稿第7句为“较少的分子间氢键和较低的结晶度会因分子链活动性提高而进一步提升……柔顺性、可及性和保水值”。原文明确改善柔顺性，并列以活动性、可及性、WRV作解释，不建立活动性→可及性/WRV的独立因果链。

现有`critical_claim_indexes`对该草稿只返回索引4、5；没有匹配“会因……而……”的第7句。v3三次都没有该句的`claim_check`，也没有修订它。只检查“拟议修改”不能保证发现“模型未提出修改的错误”。旧版3次中两次主动发现并修正。

归因更正：上一轮v2.1报告说第31题“修订引入”此因果链不准确。逐字回查确认该句原在初始草稿中；之前v2修好了，v2.1漏修。原分数仍成立，错误在成因描述；旧冻结HTML/JSON保留，说明文档已更正。

### 第23题：第一次未修引用

v3首次保留原草稿，冲突句含正文0.912与摘要0.888，但只引用摘要[2]。后两次补上[1][2]。按既定逐陈述引用组规则，前一句的[1]不会自动算到后一句。

### 第32题：已经检索到，却被保护预算挡住

v3第二、三次均已按位置找到同一摘要候选，包含0.888/0.889。不是检索漏召回，也不是重排阈值丢弃。新增测量解释同时引用了较长的XRD方法[3]，使首轮修订后受保护原文由19920字符升至22989字符。

24000字符总预算下，可删除的未引用块不足以腾出摘要空间。日志明确记录`protected_evidence_budget`，因此没有加入摘要，也没有启动第二轮审校。最终答案仍只写正文0.912/0.889，漏掉摘要冲突。第一次v3与三次旧版都成功补入摘要。

说明：增强证据解释并非没有代价。第一轮添加引用，会改变后续哪些证据可移除，间接阻碍纠正所需的新证据。

## 下一步建议

不启用整个v3，不继续堆叠提示词。下一轮先分别处理三件可定位问题：

1. 修订绑定原句内容或指纹，编号与原句不一致时只拒绝该修改；避免用错误索引覆盖其他句子。
2. 扩展因果句识别与语义核对，覆盖“会因……而……”等结构；每条检查明确原因、结果及原文关系，不能仅比较词语重合。
3. 补查预算预留或按实际引用片段精简保护范围，不能直接丢掉已引用证据，也不能仅增加提示词使保护上下文越来越大。

测量边界指引可单独做消融验证，确认是否能保住第18题收益且不造成第32题引用扩张。以上是后续工作，本轮未擅自继续修改或重跑。
