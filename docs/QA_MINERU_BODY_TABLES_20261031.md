# MinerU分类、小节补全与表格行检索合并版本

2026-10-31。将表格行检索和明确正文—表格关联，接入用户已确认的分类、小节补全方案。原113块分类快照不改写；独立建立可运行向量索引。本轮没有切换网站默认配置、部署服务器或生成新的问答质量分数。

后续规则更新：用户要求表格和公式直接命中时也能触发可靠小节补全，已实现。以下为本合并版本初次建立时的规则和验证记录；当前行为见[科学小节补全v3](QA_SCIENTIFIC_SECTION_CONTEXT_V3_20261031.md)，原索引与旧结果保留。

## 组合后的处理流程

1. 沿用原生117单位→章节组织107块→内容分类113块的原文与章节映射，不重新调用MinerU，不改变块内容或分类。本版本没有叠加95块局部视觉修正版，也没有自动开启重排或回答指引。
2. 113个完整原文块建立BGE-M3／1024维主Chroma索引；2张原表另外生成20条带表头、已有单位和分组的行检索文本。行表示仅参与检索，不作为原文引文送入回答模型。
3. 每个问题只生成一次向量，复用到主块检索和行检索。行命中返回完整父表；按父表最大余弦分数合并去重，最多50个候选、0.35阈值、最多8个主命中。该分数不是答案正确概率。
4. 正文优先按可靠小节补全。只有缺少可靠小节的正文且存在明确同页续句时，才补邻块；小节达到预算不再绕道兜底。摘要、作者、机构、日期、关键词、参考文献和不确定块只保留自身。
5. 正文显式出现Table编号时可以补完整表格；表格可以补最多2个明确讨论它的附近正文。表格不会触发整个小节或任意邻块补全。表格是本次新增的非正文扩展例外，其他非正文规则不变。
6. 关联只允许同文献、已识别的正文与表格，当前自动生成10条有向关联。分类不明、摘要、参考文献等不能借此扩展；加载旧版含错误类别的关联时明确报错。正文中程序添加的章节前缀不作为建立关联的依据。
7. 共用单条8000、全部24000字符预算。先预留所有主命中；小节已经包含的表格、已经命中的表格不重复加入。关联阶段每条原证据最多补2块，总计最多补8块，不递归遍历新增内容。预算不足则整块省略，完整表格不截断。

表格作为主命中时仍保持完整独立证据；关联补入的说明另有引用编号及自身页码。检索诊断记录主命中、小节候选、关联增加／省略和行检索分数，避免把结构补全来源当作独立检索命中。

## 调用和限制
