# DeepSeek证据审校：实现、评测和本地启用

2026-11-02。已接入“原稿生成→引用结构校验→一次证据审校→有依据的最小修订”。回答与审校均使用DeepSeek Flash / High；MinerU、Qwen3-VL、原图、原问题与改写查询、重排和上下文补全保持不变。

## 实现行为

审校只收到本题用户问题、同一批证据/原图和本题的已校验草稿，不读取参考答案、评测要点、旧分数、其他题答案或未检索到的论文内容。

检查条件、测量口径、不确定性、推断边界、子问覆盖和引用。修改以原稿陈述下标定位，每个问题要有说明、源文引述或已附图像定位、替换陈述。必要限制须进入实际显示的回答，不能只留在审校说明。正文引用必须在相应实际片段中找到；只规范化排版，不从全文补写漏掉的词。原图以已交付引用编号、资产标识和哈希校验。

独立编辑分别验证，避免一个噪声引文使其他修改一起失败；合并后再次执行原引用结构校验。原本正确且不需修改的陈述原样保留。审校API失败、输出耗尽、修改无依据、组合冲突等情况保留原已校验答案，明确记录failed/rejected，不冒充审校通过。一次请求最多一次审校，无自动重试；若剩余HTTP预算不足，跳过审校并记录skipped。

历史记录保存原稿、发现的问题、证据、逐项接受/拒绝情况、最终稿、用量和耗时。没有改变数据库表结构或增加第二个回答模型，也没有替换原引用校验规则。

## 实际修好了什么

- **第4题条件：**把3.33与1.77 N/mm的不同作用力明确写入最终答案，保留63/57 °SR及适用范围。必答P3从0.5到1。
- **第15题不确定性：**把确定归因改为“文献推测、可能”，恢复原文might的强度。P2从0.5到1。
- **第16题推断边界：**删除已排除纤维本身变强贡献的过强说法，明确“没有降低”不能推出“一定提高”。P3从0.5到1。
- **第23题引用：**冲突句同时引用正文0.912和摘要0.888，单句证据完整。Jev把新增正文引用判无实质支持，Codex依据句内0.912事实纠正。
- 第12题将可能引起统计检验误解的“显著高于”改为“明显高于”；第13、20题保留作者机制解释的可能性；第25题把全文缺失声明限定为当前证据缺失。这些更谨慎的表达不自动增加必答要点分。

本轮没有看到新增数值错误或必答要点回退。剩余独立要点扣分为第18题相对峰面积与绝对氢键数的限制，以及第32题摘要冲突值缺失。第18题说明同一模型审校仍会漏检；第32题没有必要证据，审校不能代替检索。

## 开销与失败

正式v3新增32次DeepSeek审校，报告Token合计430,312（输入307,969、输出122,343），中位增加**12.18秒**；最大请求超时120秒、输出上限16384 Token。三个输出耗尽案例的用量仍计入，原答案保留。相对生成原32份答案的已知362,665 Token，审校额外用量约118.65%；这不是费用涨幅，实际缓存计费和货币扣费未知。答案总字符8041→8173，增加约1.64%。

Jev本轮共76次请求，API报告费用$0.241108434，包含无效尝试。v2另有32次审校396,325 Token、76次Jev请求$0.241360350；最早4题试运行另用53,374 Token。全部开发过程68次审校、880,011已知Token、152次Jev请求$0.482468784；不包含此前原稿生成或最后HTTP验收。Codex离线补评/复核未额外调用评分API。

单篇已见开发集只能说明本次固定草稿结果，不能证明换论文后的泛化或多次稳定性。提高输出上限后仍有截断，因此没有继续无限加预算或挑选重跑。后续优先在新题上验证收益及开销，并检查测量口径漏检。

## 本地启用与验收

本地`backend/.env.literature`及千问配置已启用一轮审校，模型仍为DeepSeek Flash / High。已保存原私有配置备份。配置开关：

```dotenv
RAG_EVIDENCE_REVIEW_ENABLED=true
RAG_EVIDENCE_REVIEW_TIMEOUT_SECONDS=120
RAG_EVIDENCE_REVIEW_MAX_OUTPUT_TOKENS=16384
```

将开关设为false即可恢复原流程，无需重新建索引。服务器尚未部署本次变化；GitHub推送只同步代码和不含密钥的报告。

136项相关测试通过，覆盖原引用规则、最小编辑、错误定位、独立修改组合冲突、截断/API失败回退、HTTP时间预算和历史保存。真实本地HTTP问答验证完成：1次首稿生成＋1次审校，审校使用相同4张原图，保留正确原稿；完整请求77.718秒，其中审校35.981秒。问答与审校记录可由新访问者重新读取，浏览器从历史打开后显示最终回答及来源，未把内部修改JSON展示到产品流程。
