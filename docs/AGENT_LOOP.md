# 有限Agent循环：独立实验入口

本版本自行实现Python调度层，使用Chat Completions原生Function Calling，不引入Agent框架。不改网站默认问答流程。

## 已实现

- 模型适配层将原生tool_calls转换成ToolCall(id/name/arguments)，工具结果反向转换成对应tool消息；DeepSeek思考续接字段只在运行内存中保留，不作为公开轨迹。
- 模型自主选择现有五种工具，沿用run级证据编号。图片工具返回原图像素，通过图像消息实际送给模型，轨迹保存图像载荷摘要及来源，不重复保存base64。
- 默认模型请求最多6次（含最终回答和复核）、工具尝试最多8次、总时限240秒、取证阶段预留45秒给收尾、单次输出8192 Token。
- 取证最多使用模型次数上限减2轮。达到工具/取证预算后禁用工具，请模型用已有证据回答并声明缺口，再在剩余时间内复核。
- 多工具批次逐项检查预算；重复相同参数调用（忽略reason差异）被拒绝并计数；失败工具也计数。超过上限的调用返回明确blocked消息，不执行。
- 工具子进程采用剩余取证时间作为timeout。模型请求timeout不超过剩余总时限；CLI外层在总时限+5秒清理宽限后终止Windows进程树。
- 文本上下文默认最多160000字符，图像base64单独限制为24MiB。超限明确结束，不静默删证据。该限制不是精确模型Token计数或美元费用上限。
- 每次模型/工具执行前后保存状态：模型输入（不含隐藏推理、图片base64）、工具声明名称、输出、调用参数、用量、失败类型及停止原因。工具原文和统一证据另存原有数据库。
- 失败复核保留最近草稿并标记partial；若未生成答案则标记failed，不将截断当正常答案。

## 审校范围必须区分

当前Agent实验使用一次“完整答案复核”模型请求，输入包含当前问题、工具结果、图片与草稿；允许模型修正内容，不增加程序语义校验。**尚未迁移旧版结构化核查、修订记录绑定、审校驱动补查和第二轮审校。** 因此这是新实验流程，不等价于既有32题关闭校验基线，不能沿用其分数。需要后续单独接入旧审校适配与评测。

## 运行

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/run_literature_agent.py --question "论文的PFI条件是什么？" --library <文献库目录> --seconds 240 --max-tools 8 --max-model-calls 6
```

自动生成run_id，也可以指定`--run-id`；已存在的运行会拒绝，避免重放付费调用。状态保存在`.rag-data/agent-runs/<run_id>/state.json`，结束后导出evidence.json。异常中断记录保留，但不提供自动恢复或用户取消API。

当前是本地开发入口；未公开新HTTP接口、未接专家模式UI、未部署。引用内容正确性及图读数仍可能出错，预算限制不能替代评测。

## 验证

自动测试涵盖适配、正常调用/回答/复核、重复调用、批次超预算、到期禁止执行、复核截断保留草稿；工具及原有问答/引用/检索回归共111项通过。

真实DeepSeek原生工具调用验证：`agent-smoke-20261105`，180秒、最多4次工具、5次模型调用。实际完成两次自主检索、草稿和复核，最终状态completed，正确给出浆浓10%、间隙0.2mm、两类作用力3.33/1.77N/mm。仅验证端到端兼容，不代表32题评分或稳定性；该次启动后补充了模型输入轨迹字段，旧运行不会被改写。
