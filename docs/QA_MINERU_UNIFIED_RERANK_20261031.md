# MinerU组合版本启用候选重排

2026-10-31。按用户要求，在当前113块MinerU分类、表格行检索、科学小节与明确关联统一补全的组合版本中开启候选重排。复用已有BGE重排服务配置，不改写索引，不切换网站默认配置，不新增答题或Jev评分。

## 当前链路

问题向量 → Chroma块检索与表格行检索融合 → 最多50个完整父块候选 → 0.35向量阈值筛选 → BGE重排 → 最多8个主命中 → 仅从这8个主命中收集小节/明确关联候选 → 一次预算分配 → 回答模型。

- 模型为`BAAI/bge-reranker-v2-m3`，通过已有硅基流动重排接口调用。
- 输入为原问题和候选完整原文，含已有章节前缀、原表题、表格HTML等。重排发生在补全前，不给重排模型发送补全后的证据组、参考答案或评委评分。
- 0.35只用于向量预筛选。按重排分数选前8，无独立重排分数门槛；原向量分数保留，重排分数与名次另存。
- 后续补全严格使用重排选出的主命中，保留表格、公式的小节补全与元数据保护。主命中原文及位置保留，来源去重，单条8000、全部24000字符预算不变，不运行第二阶段扩展。
- 重排失败时沿现有错误路径返回，不悄悄退回向量排序；超时60秒，单次调用不自动重试。

运行配置快照明确记录`mineru-unified-rerank-v1`、其统一补全版本、重排位置和输入类型，避免只看到重排标签却无法确认是否带上最新补全方案。
