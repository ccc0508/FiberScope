# FiberScope 评测工作台

在平台的 `/evaluation` 打开工作台。题库含 24 道文献题、20 道 SQL 题、20 道综合题和 6 道日常题。可按题组选择，也可搜索题号单独勾选。

## 启用

在私有 `backend/.env` 中设置一个随机的 `FIBERSCOPE_EVALUATION_TOKEN`，在私有 `backend/.env.jev` 中配置 `QA_JEV_API_KEY`。评测与问答共用 `backend/.env.literature` 配好的 Agent 和文献库。启动后端和前端后，用评测访问令牌打开工作台。缺少访问令牌时，后端不会启用工作台。

文献评分需要 `backend/requirements-parsing-review.txt` 中的 PyMuPDF。在公网使用时通过 HTTPS 访问。访问令牌与 Jev 密钥用途不同。令牌在浏览器当前标签页会话内保存，Jev 密钥只保留在后端。

## 执行与记录

- 同一安装由一个进程领取任务，所有批次合计最多同时执行 10 题。关闭页面后任务继续运行。进程重启后队列继续，运行中断的题目可以补跑或复评分。已有终稿可以只重跑评分，答题和评分版本分开记录。
- 评测历史保存在文献数据目录下的 `evaluation.sqlite3`。同一目录下的锁文件防止多个工作进程同时领取任务。备份可用 SQLite 的在线备份功能。
- 从固定题库读取参考内容，答题进程的输入只有题目和题库随附的作答说明。SQL 参考查询由服务端白名单校验，在只读数据库事务中执行。数据库数据指纹在 SQL 或综合题前后检查。索引标识、代码版本、模型和预算随运行保存。
- 界面分别呈现 Jev 原分、人工校准、任务验收和补查轨迹。运行对照只计算共同的已评分题。Jev 的原始决策和置信度可在逐题详情展开。
- SQL 同时显示参考行覆盖和行集精确对照。例如多返回一行题目要求的总计，仍可覆盖所有参考行。允许改变 SQL 表达式和列别名，保留参考要求的排序。投影差异仍由 Jev 按题意判定。原命令行评测历史保留在原目录。
