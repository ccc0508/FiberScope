# 比较陈述的事实与引用覆盖

新增可选实验`v2_comparison`，版本`bounded-corrective-review-v2.6-comparison`，继承精简关系审校、原句绑定和补查优先。默认仍v1，不切换网站或服务器。

程序标出含冲突、不一致、相比等表达的句子，将编号传给原有同次DeepSeek审校；模型同时识别其他隐含比较。新增comparison_checks记录原句、比较范围、双方事实及来源短引句，以及整句事实和比较结论是否有支持。模型须核对材料、指标、条件、统计量和范围，不得仅凭数字不同推断矛盾。

程序验证原句与编号一致、映射唯一、至少两个事实、引用编号存在、引句在对应原文中。只有模型标记same_scope且statement_supported=true时才允许自动补引；不同条件、不确定、不支持、引句无效、重复映射均标记未解决，不添加引用。普通语义修改与补引针对同一句时不自动合并，避免把原稿的映射误用于改写后的句子。

自动修改只在原引用后追加缺少的来源，不改写文字、不删已有引用。它进入现有独立修改、来源和引用验证流程，并进入需求记录；程序生成的只补引操作不再要求模型为同一句重复输出修改后关系记录，原句关系核查仍执行。日志保留model_issues、comparison_checks、citation_only_repair_indexes及最终issues，明确模型建议与程序操作的区别。

机械验证只证明目标和引用位置有效，不能证明模型对可比性及语义支持的判断正确。引句抄写不匹配仍可能阻止补引，关键词也不保证识别全部比较。未增加独立模型请求、输出预算或自动重试。

## 验证

254项相关测试通过，覆盖正确补引且文字不变、原句不匹配、不同范围、不确定或不支持、缺少比较一方、伪造引句、重复映射、无检查记录、引用已完整、同来源两事实，以及提供者请求、配置快照和原有审校/补查/API回归。新增响应格式失败的字段位置/类型记录，不存被拒绝字段值或供应商错误正文。

第23、32题沿用冻结原稿及MinerU/Qwen初始证据，分别进行一次真实审校和允许的有限补查。此为定点功能验证，非Jev评分或稳定性评测。完整记录位于`.rag-data/evaluations/comparison-citations-20261103-01`。

第23题首次及一次诊断重试返回格式无效，原答案保留；第二次只有ValueError类型记录，未保存原始响应，因此不能确定具体漏填/多填了哪个字段。之后一次明确的诊断调用保存本地原始返回，成功解析：模型报告同纸浆、同指标和同统计量，两条短原文均匹配；程序生成1项只补引用修改，把冲突句从[2]补为[2][1]，全文文字和其他引用未改，状态completed。第三次原始返回仅在本地`.rag-data/evaluations/comparison-citations-raw-20261103.txt`留档，不发布。不能把最后成功当作3次全部成功，也不能反推前两次的具体格式错误原因。
