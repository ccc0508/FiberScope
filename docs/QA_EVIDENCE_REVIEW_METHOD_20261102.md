# 固定草稿的证据利用审校实验

2026-11-02。用户要求优先改善实验条件、测量口径、不确定性和推断边界的完整表达。回答模型继续使用DeepSeek Flash / High；当前MinerU＋Qwen3-VL、原图、检索、重排和上下文补全不变。

## 实现

原回答先通过现有引用结构校验，再增加最多一次独立DeepSeek审校。审校只读取用户问题、同一批证据/原图以及该问题的草稿陈述，不读取参考答案、要点、题号专属提示或评委意见。

审校返回不超过8项有依据的最小编辑，每项记录原陈述下标、问题类型、说明、证据定位及替换陈述。允许必要的拆句、删除无依据内容，以及追加遗漏的相关子问；不重写没有问题的陈述。引用原文必须能匹配实际提供的相应片段，图像必须属于该引用号下真实交付的资产，纯资料范围检查有单独标记。程序核验的是定位和结构，不能保证模型的科学判断必然正确。

没有问题时原样保留草稿。API失败、格式无效、引文无法匹配或修订违反现有引用规则时，保留原已校验草稿，并记录审校失败/拒绝，不能标记为核验通过。不追加审校重试、不额外检索，引用校验规则也不在本轮调整。

原稿、审校问题、依据、接受/拒绝原因、最终稿、调用用量和时长分别保存到问答结果。历史SQLite存储完整结果，无需改变表结构。DeepSeek审校使用独立请求，关闭SDK自动重试，最多16384输出Token和120秒请求超时；费用未知时不估算账单。HTTP传递整次请求时间预算，若原生成后剩余时间不足以完成审校，则跳过审校并保留已验证草稿，记录skipped，避免为了审校丢失正常答案。

配置：`RAG_EVIDENCE_REVIEW_ENABLED`默认false；`RAG_EVIDENCE_REVIEW_TIMEOUT_SECONDS`默认120；`RAG_EVIDENCE_REVIEW_MAX_OUTPUT_TOKENS`默认16384。只有DeepSeek Flash可以启用。实验期间不改变网站配置，按结果决定是否启用。

## 固定对照

使用刚完成同证据模型比较中的32份DeepSeek正式答案作为封存草稿。控制组原样保留；实验组逐题独立审校一次。不是重新生成两批答案：本实验测量的是对同一份草稿增加一次审校的净变化，原生成随机性不会混入组间差异。新付费操作计划32次审校、两组各32次Jev评分；查询、Embedding、重排和第一遍生成均不重跑。

原始问题/标准、证据顺序、引用编号和原图字节相同。每题只可见自己的草稿。保留全部失败和被拒绝的修改；不按分数挑选重跑。

外部评委仅Jev，继续使用不变的`qa-system-five-v1`文字评分协议，两组独立盲评，不暴露审校标记、原分或模型身份。首个有效、最多三次；无效评分不是零分。记录全部调用和已知费用。若需要Codex补评/源文复核，另存调整依据，不覆盖Jev原始记录；涉及原图的事实按实际交付图像核查，另说明其口径。

报告必答要点、事实支持、单条引用、引用组覆盖、边界及全部达标题数，不计算加权总分。同时记录修改/原样/失败/拒绝数量，修好与改坏的具体题目，新增无依据陈述，以及审校增加的耗时和Token。此为已见开发题上的一次试验，不能证明跨论文泛化或稳定性。

## 试运行及正式设置

最初v1只试运行前4题：第1–3题原样保留，第4题思考输出耗尽8192 Token上限而没有产生有效JSON，系统保留原稿。该失败的模型用量和全部输入均保留，不将其记为修复，也不重试挑选评分。由此将正式上限提高到16384、超时120秒，并补充明确的输出截断诊断。

完整32题在新的v2封存目录独立执行，试运行4题不混入正式对照，也不隐藏其额外费用/用量。提示内容不改，只调整协议预算和诊断；仍不增加自动重试。

正式入口：`scripts/evaluate_evidence_review_v2_20261102.py`依次prepare、run、prepare-grading、grade。原始实验目录 `.rag-data/evaluations/evidence-review-20261102-v2`，审校运行目录 `.rag-data/evaluations/pfi-evidence-review-20261102-v2`；均被Git忽略。v1试运行目录与脚本保留。

## v2结果与实现复核

32次审校全部完成，25题不变、5题修订（4、13、15、20、31）、2题拒绝修订（16、24，原文引述匹配失败）。Jev原稿30题有效、审校后29题有效；5份协议无效单独补评，原始分保留。Codex按实际文本/附图统一复核全部64份回答，相同回答最终同分，避免将评委波动当作审校收益。

全部32题必答要点96.88%→97.40%，全部维度达标24→25题，明确要点收益仅第15题恢复作者“可能”措辞。新增396,325 Token，中位审校14.69秒；额外v1试运行53,374 Token单列。DeepSeek实际货币扣费未知，不估造。

第4题识别了作用力不同，但必要条件只出现在审校说明，没有落到可见回答；第16、24题存在OCR重复断句，长引文匹配失败还连带拒绝其他可独立修订之处。第18题未发现测量口径遗漏，第32题也没有缺失摘要证据可用。本轮不据此宣称解决了所有证据利用问题。

## v3：独立编辑与可见条件

根据上述实现缺陷，下一版要求识别出的必要条件、限制和不确定性必须进入替换陈述本身；对噪声原文引用短的实际片段，不能顺句补写长引文。每项修改均指向原稿下标，分别验证；一项引文失败不连带丢弃其他独立且验证通过的编辑，组合后仍运行原引用校验，冲突则保留原稿。记录每项接受/拒绝原因，不增加模型调用次数。

通用规则不含本论文题号或标准答案。新版本`source-grounded-review-v2`，重新封存并对相同32份草稿测试，不挑选v2/v3逐题最优结果。入口`scripts/evaluate_evidence_review_v3_20261102.py`；v2结果继续保留，不回写。

v3已完成：8题修订、20题原样、3题审校截断保留原稿、1题引述无效拒绝修改。经Jev原判及独立源文复核，要点96.88%→98.44%；全部达标按本轮统一单句引用口径23→27题。第4、15、16题获得必答收益，第23题引用组修复；第18、32题仍有缺口。已在本地启用，服务器未部署。完整原分、基准修正、费用及真实HTTP验收见[最终结果](QA_EVIDENCE_REVIEW_RESULT_20261102.md)。
