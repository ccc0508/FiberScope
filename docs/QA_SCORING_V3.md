# 文献问答统一评分标准 v3

2026-10-26。GPT与Jev的新评分统一使用`qa-scoring-v3`。标准的唯一程序来源为[qa_scoring_policy.py](../scripts/qa_scoring_policy.py)，两种裁判请求都携带同一份规则对象和SHA256。中文说明如下；这是评分规则细化，不是新一轮评分结果。

冻结的v2题目、原文证据、必答/可选属性和原回答保留原样。新规则以请求内覆盖层应用，不修改`fiberscope-eval-v2/rubric.json`或其manifest。GPT运行协议升级为`qa-independent-judge-v3`，Jev为`qa-jev-openrouter-v2`。

## 一、0分、半分、满分怎么区分

| 分数 | 统一定义 |
| --- | --- |
| 0 | 这个要点的核心命题未回答、答错或与原文矛盾。只回答相关背景或另一个要点，不能给这个要点加分。 |
| 0.5 | 这个要点至少一个实质组成部分正确，但缺另一组成部分、条件、单位、计算或必要限制，且没有相反结论。不能因复合要点不完整就抹掉正确部分。 |
| 1 | 这个要点的实质内容和必要限定都已清楚表达。接受同义表达及明确的逻辑等价，不要求照抄标准答案；不替回答补上仅仅“可能合理”的推断。 |

以下是规则示例，不是对历史回答重新打分：

| 要求与回答情况 | 判定 |
| --- | --- |
| 要求两个端点及单位，只给出其中一个正确端点和单位 | 0.5 |
| 要求区分两种测量方法，已分别给出峰高法与峰面积法的定义 | 1，不要求另写一句“不能混用” |
| 独立要点要求“相对光谱比例不等于绝对数量”，回答仅重复相对比例定义 | 0；相关定义不能替代独立的测量边界命题 |
| 要点要求“作用力不同，不能把差别全归于材料类型”，只写作用力不同 | 0.5 |
| 同上，回答还明确以不等的处理作用力作为另一种可能解释，保留不确定性 | 1；已经表达了归因限制，不必照抄固定警示句 |
| 要求机制A、B、C，回答只解释A、B，C既没明说也无法从文字直接确定 | 0.5 |

补充约定：

- 每个要点独立判断，正确内容可以支持相关的多个要点，但不能替代实际上没有表达的独立命题。
- 要求来源归属时，清楚映射到具体文献/章节/页码的引用元数据可以作为归属依据。若要求指出冲突、限制或因果边界，回答本身应表达该关系，不能只让读者自己推断。
- 正确说明检索不足，不免除遗漏题目所需内容的扣分；同一个遗漏跨维度关联为同一缺陷，不把各维度相加成一个总分。
- 题目已有的数值对象、浆种、转数、单位和容差继续有效；正确数字出现在不相干的语境里，不算答对。
- 可选要点的省略仍不降低必答均分或严格达标率；额外错误事实仍须检查。

## 二、全文、当次检索、具体引用分别检查什么

| 检查对象 | 允许使用的证据 | 禁止的替代 |
| --- | --- | --- |
| “论文报告某结果”是否为真 | 已核验的完整论文、标准证据及实际片段 | 把参考答案无条件当真；与原文冲突时应报告疑点 |
| “当前提供的证据没有某数据”是否为真 | 回答模型当时拿到的全部实际检索片段；若明确说某个摘录，则限定在那个摘录 | 因完整论文含该数据，就声称当前检索也有 |
| 某条引用是否支持结论 | 该引用编号实际对应的片段 | 用未引用片段、标准证据或全文修补该引用 |
| 论文/文库整体是否缺少某信息 | 完整论文或明确的文库目录、覆盖信息 | 只因某一检索片段没找到就推断全文都没有 |

支持标签统一为：有支持、部分支持、无依据、矛盾。**没有证据不等于矛盾。** 只有在陈述所声称的同一范围内，证据明确与之相反，才能判“矛盾”。不能从全文补全实际检索中被切断的单词、表行或句子。

例如：全文有目标行，但本次检索只取到表格前半段。回答说“当前摘录缺少目标行”可判为有支持；它未完成用户要求的计算仍需扣要点分。检索缺失、漏答、事实错误分别记录。

纯粹描述“当前证据缺数据”“没有提供图片能力”的陈述标`scope`；含科学事实和范围限制的混合句继续标`fact`，分别检查科学部分与范围部分。不能因为句尾加“没找到”，就免除前半科学事实的核查。

GPT可明确记录对全部当次检索的范围审阅；Jev新增`ACTUAL_RETRIEVAL_SCOPE`原文定位选项，与全文/文库范围核查分开。原始选项和依据范围均保存。

混合陈述可以同时提供已核验的科学事实引文和`retrieval_scope_review`，分别证明事实部分及当次检索的覆盖范围。范围说明不能单独替代事实引文，事实引文仍逐字核验；这条兼容复核不更改裁判分数、引用或原始响应。

## 三、允许多个引用联合支持，但检查是否完整

评分分为两层：

1. **单条引用贡献。** 指定片段是否直接支持句子中至少一个具体、实质的科学事实？是则1，否则0。对象、条件、单位和来源定位必须正确；仅仅主题相似不算支持。一个片段不需要重复证明另一个片段已经支持的其余部分。
2. **整组引用覆盖。** 仅使用这句话实际附带的所有引用，是否覆盖了它的全部事实、比较/计算输入和必要限定？分别记`complete`、`partial`、`missing`。纯范围声明不进入事实引用分母，记`null`。

| 回答及证据 | 单条引用 | 整组覆盖 |
| --- | --- | --- |
| 句子包含A、B；[1]直接支持A，[2]直接支持B | 两条均可得1 | complete |
| [1]、[2]都只支持A，没有任何被引片段支持B | 两条均可得1，但不能据此判整句完整 | partial |
| [1]已经支持全部内容，额外挂了完全无关的[2] | [1]为1，[2]为0 | 可以complete，但引用精确率及严格达标仍受无关引用影响 |
| 全文支持B，但该句实际引用均未包含B | 不能用全文修补引用 | 至多partial |
| 被引文本在关键结论前截断 | 不根据全文补全截断内容 | 按实际可见内容判断，缺少部分不能算complete |

联合证据可以支持清楚、有全部输入的计算或有边界的比较。相关关系不能自动升级为因果关系，也不能凭高相关系数补出未提供的定量预测公式。

指标定义同步更新：

- `citation_precision`：有实质贡献的事实引用数 / 全部事实引用数。
- `citation_coverage`：引用组完整的事实陈述数 / 全部事实陈述数。不是“有一条相关引用就算覆盖”。
- GPT的严格达标、Jev的共有维度达标，都要求引用组完整，且没有无效的额外事实引用；两者原有的其他评估范围差异仍存在。
- 新字段`citation_group_assessments`保存每条陈述实际引用集合、完整性标签及依据。Jev保留原生选择，程序不补写自由文本理由。
- 混合句的科学事实部分仍需完整引用支持，其“没找到”等范围部分另按实际证据范围核对。

## 版本、保存与执行

当前工具默认使用新规则。调用方式仍见[GPT评分工具](QA_INDEPENDENT_JUDGE.md)、[Jev评分工具](QA_JEV_JUDGE.md)，**必须使用全新的评分输出目录**，例如包含`scoring-v3`和轮次的名称。

每次新运行保存规则版本、规则对象指纹、请求指纹和实际工具副本。题目指纹仍指向原冻结题集；运行规则指纹单独保存。引用组评分由指定外部裁判产生，程序只校验和汇总。

旧GPT v2、Jev v1提示保留用于重建旧请求、验证旧响应和旧结果，旧评分不会被程序转换成新规则下的分数。旧目录继续收费调用应使用原归档工具；当前新工具不会静默续跑旧目录。比较与汇总工具拒绝混合新旧规则的评分。

本次已离线准备32题两种裁判的新输入，核对旧Jev三轮共96份请求及有效语义结果仍可原样复核，并复核旧GPT三轮95份有效评分，原件均保持不变。没有重新生成RAG回答，没有调用评分API，尚无v3正式分数。程序测试不等于证明裁判会正确遵守规则；实际裁判效果仍需后续独立评分和抽样核验。

历史分歧见[原文复核报告](QA_JUDGE_DISAGREEMENT_REVIEW_20261026.md)。后续规则示例使用合成情景，不把历史模型分数或逐题复核意见作为裁判输入。
