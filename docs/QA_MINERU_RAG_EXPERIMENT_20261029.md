# MinerU文本RAG独立对照实验

2026-10-29启动。使用已取得的同一14页论文MinerU精准解析结果，建立独立索引并重跑原32道核心文本题。2026-10-30已完成答题、双评和报告，见[实验结果](QA_MINERU_RAG_REPORT_20261029.md)。

## 比较范围

- 主对照：当前PyMuPDF文本结构版，81块，同页邻块补全已开启。
- 实验：MinerU原生块文本索引，117块；相同BGE-M3/1024维、DeepSeek Flash/High、最多50候选、top_k=8、min_score=0.35、邻块半径1、8,000/24,000字符预算。
- 参考：原44块版本及DSH既有回答与评分，保留归档，不重复生成或择优评分。
- 原PDF哈希、题目、标准答案、要点和共同五项评分规则不变。每题独立请求，不向答题模型提供参考答案或旧分数。

MinerU的161个原生块经确定性适配形成117个有文字的检索块：48个正文、16个标题候选、5个公式、9个图注、2个表格、37条参考文献。只排除30个页面辅助块和14个没有可索引文字的块。

保留MinerU原生边界、重复文字、HTML表格、科学符号和错误标题，不人工修正，不根据题目调整块。表格保留表题、表体和表注；图像只使用已有图注/文字，不启用视觉模型。单个原生块超过8,000字符时明确拒绝，不能截断内容。

这比较的是“MinerU解析结果及其原生块适配”与“PyMuPDF及当前规则切块”两套文本流程；块组织方式也不同，不能将差异单独归因于解析器。

## 原文与评分核验

- 保存原生块编号、类型、原始层级、bbox和页码到结构清单，连同原文快照一起冻结；当前回答接口仍沿用既有引用格式。
- MinerU生成的引用片段额外与原PDF两种文本抽取结果核对。不匹配标为需原页复核，并将对应原页提供给评委；排版差异不自动判错，也不补造正确数值。
- Jev与Luna独立评分，使用同一共同五项协议；最多三次评分尝试，只接受首个有效结果，失败保留为缺失。
- 主比较按每位裁判均有效的相同题目配对；多系统共同集合另列，不混用不同分母。
- Embedding、答题、评分用量分别记录；复用的历史评分不计入新增API费用。
