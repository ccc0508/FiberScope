# 关闭内容校验：固定模型输出实验

按用户要求，隔离实验中关闭审校内容检查：不验证引据、语义核查单元、原句锚文本、修改后引用，不规范化修改文字。仅需JSON可读、目标编号可执行、替换文本与引用列表可渲染；不存在可执行目标时会记录失败。线上默认未改变。

输入是上一轮32题35轮保存的原始模型输出（有归档时优先用原始响应；否则用model_issues）。各轮独立使用当时草稿，不把后轮旧输出套到新草稿上，不伪称完整的反事实多轮运行。本次没有新模型调用、没有Jev评分。

## 结果

模型原始提议22项，全部可执行，涉及15轮。此前v3.2重放计23项，是因为其中包含23题一项程序自动派生的引用补齐；本实验只执行原始模型提议，明确排除该项。

- 4题：完整序列修订执行，但同一条件、需要提高转数仍在；核心错误漏检，不是放行能解决。
- 14题：因果解释修订执行，但分子链本体断裂仍在，未提出该项纠正。
- 15题：成功恢复作者推测、可能因为的限定。
- 18题：相对峰面积不等于绝对数量，以及图7软木范围/方法引用均进入答案。正文还含内联[1]且末尾再次引用，原格式问题也直接呈现，未清理。
- 24题：删除最直接排名，修正总量为相对量；但后半句仍把柔顺性、可及性、WRV当成三个直接结果，修订本身不完整。
- 31题：三项均执行，相对指数、相对氢键量、可能原因及收窄因果结果得到表达。这是保存修订的内容观察，不是新评分或稳定性结论。
- 32题：首轮相对量限定执行；独立重放第二轮时，摘要0.888/正文0.912冲突及换算限制都进入答案。两轮分别展示，不叠加成未经运行的最佳答案。

## 能推出什么

确实有正确修订被原校验挡住，尤其15、18、31、32。关闭检查同时暴露了尚未修复的语义错误和格式瑕疵；不能由22/22执行认定22/22正确，也不能由单篇保存输出证明无校验普遍安全。当前不加回新规则，先保留可对照结果。

后续若做新一轮无校验模型运行，应固定模型/提示/初始证据，明确多轮时新答案影响后续上下文；另做Jev与来源复核。最小结构检查（编号/重复目标执行策略）和文字展示规范化应与科学内容判断分开，引用可先作为事后诊断而不是一律阻止整项修改。哪些内容校验恢复应以误改证据为准。
