# 植物纤维术语

侧栏“科研助手 → 植物纤维术语”进入 `/glossary`，子路径部署时为 `/fiberscope/glossary`。

## 使用

- 共43个术语，分为打浆与回用5个、纤维形态19个、纸张性能15个、机理与方法4个。
- 可按中文、别名、英文名、单位及指标键搜索；空格分隔的多个关键词须同时匹配，兼容 μ/µ 两种微符号。
- 分类与关键词组合筛选，清空结果时提供重置入口。URL保存 `q`、`category` 与 `term`，支持刷新恢复和单条术语分享。
- 详情包含定义、如何理解、读数注意点、适用时的单位/计算关系/示例、相关术语和分析页面入口。
- 电脑端为目录与释义双栏，手机端为可滚动目录与下方释义，选择条目后定位到释义。支持键盘操作及复制本条链接。
- 按用户要求移除全部参考资料列表、外部引用链接、右上角“内容与来源”及底部来源说明；术语内容和数量不变。

## 内容口径

以用户提供的《srp表格数据初步研读》为基础，合并零距抗张、耐折度和纤维粗度等重复内容，补充平台已区分的平均长度、细小比例及原始强度条目。
术语关联覆盖 `backend/app/catalog.py` 的全部34项测量指标，以及打浆转数和打浆度。页面为静态解释，不请求数据库，不自动计算或写入实验数据。

保留平台透气度单位暂定、耐折度单位与报告形式未确认的状态。区分强度与指数，粗度换算保留量纲；零距抗张解释为规定试验下的间接指标。
不把细小组分不同权重、投影面积与真实比表面积混同，不通过通用定义补造仪器算法或未知处理条件。
PFI采用方法名称，不沿用研读稿中未经核实的英文全称；中浓打浆不强设统一浓度区间。

页面不展示来源资料。具体测量以原始试验方法和仪器报告为准。

## 维护与发布

术语集中维护在 `frontend/src/glossary.ts`，界面为 `frontend/src/pages/Glossary.vue`，路由按需加载。
无需新增依赖、后端接口或迁移。页面发布仅需更新前端，无需重启后端或改动数据。
