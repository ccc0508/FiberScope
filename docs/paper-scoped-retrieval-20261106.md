# 指定论文检索与定义表索引（2026-11-06）

## 已实现

- `find_documents(query, offset)`：按文件名、已解析标题和已分类作者信息查找论文，空查询分页列出目录。返回论文编号，不产生引用证据；作者分类缺失时可以按标题或目录识别。
- `search_literature(query, document_ids?)`：不传编号保留全库检索，传一个或多个编号则在向量候选、表格行和图片候选检索时限制论文范围，随后沿用重排和上下文补全。未知编号拒绝执行。论文过滤不等于排除该论文的参考文献段。
- `find_table(document_id, table_number, offset)`：通过原表题中的明确表号返回表块编号、页码及小节位置，再由 `read_table` 读取原表。重复匹配全部返回，不擅自选定。目录和定位结果不作为科学证据编号。
- 表格行索引扩展：支持具有列名的变量/定义/单位表，以及输入变量、输出变量分组下的符号定义表。保留原值、原单位、原始行偏移；没有列名的符号定义表明确使用程序标注的列位置，不伪造原文表头。检索表示不是引文，命中仍返回完整原表。
- Agent提示词增加论文发现、限定范围补查和按表号读取路径；检索次数与总工具预算未改变。
