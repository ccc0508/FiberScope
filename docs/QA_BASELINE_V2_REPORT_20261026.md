## 下一步优先处理

1. **表格与相邻证据检索。** PFI2-010、011、021暴露了数值证据不完整、复述引言替代本文实测结果、没有取全计算端点的问题。先针对这些题检查表格切块、相邻片段与检索排序；仍需用同题复测验证改进。
2. **回答完整性和证据边界。** PFI2-004所需证据已被裁判标为complete，仍遗漏条件差异；018遗漏“相对峰面积不等于绝对数量”的限定。需要在回答前核对问题的每个子要求。
3. **限制贡献排名和因果推断。** PFI2-024把定性解释写成“主要贡献”“主要来自”等强判断；不能据此替代独立贡献或控制混杂后的分析。
4. **逐条约束引用与追加内容。** PFI2-027虽满足必答，但混合事实陈述中的“未报告”部分没有得到所附片段支持；032正确纠正了核心系数，仍追加了超出证据的相关性断言。
5. **提高评测工具稳定性并做专家抽查。** 本轮裁判有字段和引句错误、服务超时；结构化输出、去除重复上下文以及专家校准应在后续比较中纳入，并冻结同一裁判规则重评基线和优化版。

## 结果的使用范围

这是单篇论文、32道公开开发题的一轮独立模型评阅，尚未经领域专家盲评，也没有多次重复运行或独立测试集。因此不能把90.10%解释为实际用户问题的正确概率，不能据此宣称优于通用Agent。
旧30题报告使用旧题集与Codex来源初评；这轮题干、标准和评分者不同，分数不能直接作为算法进步或退步的证据。后续优化应在同题、同库、同回答配置和同裁判规则下比较。
程序的原文检查能证明引句确实存在；“原文是否支持结论”仍是模型裁判的判断。下一步应抽查关键错误、部分支持和范围边界，再固定规则开展优化。评测方法参考[OpenAI官方评测指南](https://developers.openai.com/api/docs/guides/evaluation-best-practices)。
