# MinerU章节识别与正文组块实验

2026-10-30。复用上一轮同一PDF的MinerU精准解析结果，不新增PDF解析请求。

## 本轮改动

- 使用标题候选、编号、原始层级和位置恢复章节树；编号深度优先于MinerU扁平的`text_level`。
- 将论文总标题保存为文献信息。标题不再单独向量化；正文、公式、表格、图注和参考文献携带程序生成的章节路径。
- 标题展示标签只消除确定的重复；原始标题全文及位置仍保存。粘连标题的前缀作为原文片段保留。纯数值加单位的标注不建立章节，含软件版本的正文不当标题。
- 同小节短正文在满足相邻条件时合并，长正文按句末标点或空白边界分开，以1,200字符为软目标。跨页合并仅用于有连续句子特征的情况；跨页章节归属独立保存。
- 单块最多8,000字符，包括章节标签。表格、图注、公式和参考文献保持原子单位，超过预算明确失败，不截断数据。

## 控制范围

本轮只改变入库前的章节标签与组块。BGE-M3/1024维、答题模型与High档位、问题、提示词、50候选/top8/0.35阈值、同页邻块半径1、8,000/24,000字符预算、评分规则不变。

章节标签明确标为程序整理的元数据，参与Embedding，也会随原文提供给答题模型；引用需回查保留的原文片段和原PDF。由于检索块边界和页码范围改变，相同邻块算法的实际补充内容也会变化，这属于本轮索引适配的效果。

尚未实现按整个小节补全上下文、表格行级检索、参考文献分流、重排、图片理解或回答完整性提示改写。正文重复、公式符号与表格HTML原样保留。实验索引独立，应用默认配置不自动切换。

## 工具

- [章节组织程序](../scripts/mineru_sections.py)：不读取评测题目，不调用模型，支持编号层级、无编号标题和不确定归属回退。
- [预览与独立索引构建](../scripts/index_mineru_sections.py)：默认只生成离线预览；显式`--embed`才调用Embedding。建库前核验预览、规则及原PDF指纹。

单篇真实论文和不同格式的合成测试用于验证确定性与数据保全，不证明对所有论文格式都能正确重建章节。后续质量结论由原32题和同规则双评实验给出。
