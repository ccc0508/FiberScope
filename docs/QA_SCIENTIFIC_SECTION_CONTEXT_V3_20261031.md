# 正文、表格与公式共同触发小节补全

2026-10-31。按用户要求，将直接命中的表格、公式纳入可靠小节补全范围。复用刚建立的113块MinerU分类库及其表格行索引，不重新解析、切块或Embedding，不切换网站默认配置。

## 当前规则

| 主命中类别 | 可靠的小节归属 | 缺少可靠的小节归属 |
| --- | --- | --- |
| 正文 | 按小节补全 | 仅明确的同页正文续句可以邻块兜底 |
| 表格 | 按小节补入正文、公式、其他表格等科学内容 | 保留本身；仍可通过明确表号关联补说明正文 |
| 公式 | 按小节补入正文、定义、条件等科学内容 | 保留本身，不启动邻块兜底 |
| 摘要、作者、机构、日期、关键词、参考文献等 | 保留本身 | 保留本身 |
| 类别不确定或混合 | 保留本身 | 保留本身 |

图注暂时仍不主动触发小节补全，但可作为科学小节的补充材料。小节的可靠性由已保存的结构状态检查决定，不代表独立人工审核正确率。补充候选来自同文献同小节的科学内容和原有明确表号关联，没有调用模型判断每段是否必要。

完整表格和公式仍是独立的检索块，本轮没有把它们重新切开或绑定变量解释。区别发生在检索之后：单独命中表格或公式时，也能把小节中的解释补入最终证据。

## 保留与去重

- 所有主命中先完整预留预算，表格和公式各保留自己的证据锚点，不因同小节的另一个主命中被吞并。它们的证据文本可以附带解释，但来源列表仍逐项保存完整原表、公式、页码及各补充块。
- 主命中的表格、公式和正文不会被其他组再次作为补充来源消耗；补充块在全部证据中最多出现一次。
- 同小节多个正文命中仍可合并。小节范围过大时受单条8000／全部24000字符限制，不承诺整节全部返回。
- 科学小节补全之后，再执行明确正文—表格关联；已经提供的内容跳过，不递归沿新增内容继续扩展。
- 未确认小节的表格、公式不会因为紧邻其他块就触发兜底。正文原有续句兜底规则不扩大。

运行版本分别为`scientific-section-context-v3`和开启行检索时的`scientific-section-table-evidence-v2`。配置入口仍为`RAG_CONTEXT_EXPANSION_STRATEGY=body_section`，兼容现有候选配置。

上述均为来源与流程验证：没有新增解析、Embedding、重排、回答或评分调用。未声称答案质量提高。
