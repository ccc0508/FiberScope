# GPT与Jev评分分歧复核

2026-10-26。结论：两者均有可确认的误判，不能把GPT、Jev或两者多数票直接视为标准答案。Jev重复性高，但第10、21题的证据范围判断连续三轮相同地出错；GPT在部分漏答和引用配对上也有过宽或摇摆的判断。

本文件是应用户要求，由Codex结合保存的回答、实际检索片段、冻结规则和原始PDF作出的**非盲复核意见**。它不是领域专家金标准，不覆盖任何历史评分，不重算正式总分，也不据此估计裁判准确率。本次没有新增模型API调用。

## 三个需要重点解释的例子

### 第15题：不能把已有的条件分析判成完全没答

回答已经说差别“可能是因为阔叶木纤维打浆时施加的 refining pressure 较低”，并列出针叶木3.33 N/mm、阔叶木1.77 N/mm。原文第4页也把较低压力列为可能原因，第2页给出不同作用力条件。

因此，“作用力不同”是直接覆盖，“不能只归因于浆种”至少已通过替代解释有所表达。Jev连续三次给0过严。GPT的部分分最保守；接受语义推论时满分也有理由。这不是回答完全遗漏，也不是要求必须复述标准答案的固定句子。

### 第18题：正确的比例定义，不自动等于完整的测量边界说明

回答已解释按子带面积占比得到相对含量，原文第8页确实使用面积比例。它没有宣称测得了绝对氢键数量，也没有明确告知不能这样解释。

因此不能给该边界要点满分，但0和0.5的选择暴露了规则重叠：P2已考相对含量定义，P3另考不能当绝对数量。后续应固定“仅重复P2不算覆盖独立P3”或“正确口径但未明示边界给部分分”中的一种规则，并配正反例。当前不宜把这项分歧全归咎于某个裁判。

### 第21题：回答不完整，与回答说错，是两件事

原文第8页表2b有阔叶木4000转33.06%、12000转29.28%。据此可算下降3.78个百分点，相对变化约−11.43%。

但当次检索的[8]在阔叶木8000转一行中途结束；检查保存的全部8段检索证据，均无29.28。回答说“所给表2b摘录只显示到8000转”，与它实际拿到的文本一致。它又指出不能从整个过程的8.8%增幅反推12000转值，这个限制也合理。

GPT三轮均把这些陈述判为有支持，Jev三轮均判为矛盾。**就这两个支持标签，GPT更对。** Jev的矛盾标签不成立，不能因为全文含数据就否定针对当前片段的缺失声明。但该回答仍没有完成用户需要的计算，必答要点不能因此给满分。平台应改善表格切块或补充检索，评分也应区分检索不足、回答遗漏与事实矛盾。

## 对后续评分设计的影响

1. **先固定含糊规则，再决定裁判分工。** 明确隐含但合理的条件说明何时给部分分、何时算完整；把“机制A、B、C”这样的复合要点拆开或列出部分分示例。规则修订建立新版本，旧版本继续冻结。
2. **明确三种证据范围。** 全文核对科学真伪；当次实际检索核对“找到/没找到”；某一被引片段核对具体引用支持。禁止用全文内容补成当次检索输入。
3. **明确联合引用。** Jev提示词要求单个片段支持整句所有事实，GPT提示词没有同样明确展开这个严格要求；两者实际任务存在措辞差异。后续应统一选择拆分原子陈述，或评估一组引用是否联合支持，再做同条件比较。
4. **混合句先拆分。** 对“论文报告A，但没有获取B”分别评事实与证据范围，避免裁判标scope后把A的引用检查也免除。
5. **暂不把任一模型设成最终裁决。** Jev可继续承担快速结构化初评，GPT补充复杂因果、范围、冲突解释；分歧进入源文核对。不要把“两模型一致”当作必然正确，也不必为每条简单题重复调用多个模型。

本轮只选中了分歧条目，且复核者已看过模型分数；没有独立专家盲标，也没有检查所有两模型一致的条目。因此不报告“GPT准确率”或“Jev准确率”。后续若要衡量裁判质量，应另建固定的专家核定子集，并包含一部分双方一致的样本。
