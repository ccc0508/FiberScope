# 有限触发的多结果与因果链核查

新增可选实验`v2_causal`（`bounded-corrective-review-v2.7-causal`），继承比较引用补全和精简关系审校。默认配置未切换，未部署服务器。

仅当回答包含因果表达，并出现并列对象或进而/进一步等链式表达时，触发详细核查。数值陈述、仅相关性陈述通常不触发。规则不依赖题号，属于启发式筛选，可能误选并列原因，也可能漏掉隐含关系；不是精准语义分类器。

每轮最多3条原句、3条拟议修改，每条最多6个结果。普通关系检查仍保留，新增详细检查不替代原句绑定、引句匹配、引用校验或比较来源规则。原句超额记录detail_budget_unchecked，拟议修改缺乏详细核查则拒绝该修改，不默认通过。

完整原句从已有证据定位，不新增检索或重复发送全文。输入提供最多48个来源句子起止位置，模型引用位置并逐项列出回答声称的结果是否受支持。程序核对位置属于标点结束的原文句段，短引句位于该句段内，且supported判定与结果列表一致。小数点不切开；超过1800字符及无句末标点的尾段不作为候选。不修复OCR，不拼造原句，句段识别不是PDF完整性保证，缩写/布局和截断仍可能影响识别。

模型须核对全部结果箭头、方向、条件和确定性，不把并列解释写成因果链；有依据的多个结果必须保留。仅删多出来的关系，保持正确结论。不支持某个结果时不能整体标supported。程序不能证明模型真的列全了每个结果或语义判断正确，仍需源文复核。

同一审校请求完成，无新增模型调用，32768上限及两轮审校/一次补查不变。额外位置与结果字段仍会增加输入或推理消耗，尚无实测降本/质量收益结论。本轮没有调用收费模型、Jev，也没有重跑第31题。

验证包含：多结果与链式触发、普通相关不触发、小数与尾段边界、真实支持多个结果的保留、错误箭头拒绝、超额标记、协议继承与同次请求预算。详细上下文记录在每轮causal_detail_context，便于后续检查实际触发对象。
