# 仓库内容管理

GitHub 仓库保留前后端源码、数据库迁移与导入器、依赖锁、通用部署模板、运行说明、评测题集和生成脚本。

部署现场记录、个人汇报、项目分工与交接材料、生成的评测报告、解析对照产物、完整请求快照和交付材料不随源码发布。它们保留在本地私有资料中，所需运行脚本仍可读取本地材料。

原始研究数据和字段解释用于建库与来源追溯，保留既有文件与指纹，仅限获得授权的项目用途；发布范围须按数据授权另行确认。真实环境文件、凭证、数据库备份、问答记录与运行时索引始终保存在本地或私有运行环境。

2026-11-11 按要求清理 GitHub 分支、标签及其历史中的上述材料，操作在独立副本进行，原项目本地文件保留。GitHub 的 PR 历史引用和缓存由托管平台另行管理，不受普通分支推送控制。

历史重写后，原有克隆包含旧历史。继续开发应从清理后的远端新建克隆，再迁移所需的未提交更改；不要把旧分支历史合并或强制推回远端。更新后的忽略规则用于防止再次误加本地材料。
