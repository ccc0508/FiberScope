# 正文小节补全优先，续句邻块兜底

2026-10-31。按用户确认的规则新增`body-section-context-v2`，原`role-context-v1`及已封存实验保持原样。本轮只验证程序行为，不新增付费答题或Jev评测，不声称评分提高。

## 决策顺序

1. 首先检查内容角色及其可靠性。不确定或混合块只保留主命中。
2. 作者、机构、日期、关键词、摘要、参考文献等非正文命中只保留自身，不触发邻块或小节扩展。同一摘要即使有其他片段，本版也不自动扩展。
3. 已可靠归入小节的正文直接走有预算的小节补全，无须先出现续句迹象。允许可靠同小节内容跨页；必要的完整表格、公式和图注可作为正文的补充材料。
4. 只有缺少可靠小节归属的正文，才检查同文献、同页、直接相邻、同归属范围、已识别为正文的候选。现有英文续句规则要求前块未以句末等终止标点结尾、后块以小写字母接续；不明确的情况保留原块，未宣称覆盖所有语言及断句形式。
5. 小节补全达到长度预算后跳过放不下的候选，不再启动另一套邻块扩展绕过限制。没有可靠小节、也没有明确续句关系时只保留主命中。

表格命中保留原块中已有的表题、表头、单位和表注；单独命中表格、公式、图注也不会主动扩展到其他块。正文显式关联表号时仍可补入对应完整表格。主命中的表格保持独立，不因同时命中正文而重复加入或被其他证据组占用。

所有主命中先预留完整空间；每条8000、全部24000字符上限不变，保留来源块及页码，不截断表格，不因补全丢弃主命中。小节候选仍为结构候选，并不代表已经经过模型判定与问题相关。

## 应用接入

实现：`backend/literature_rag/application/body_context.py`。检索器支持传入校验后的正文补全目录，问答工作进程提供可选策略：

```dotenv
RAG_CONTEXT_EXPANSION_ENABLED=true
RAG_CONTEXT_EXPANSION_STRATEGY=body_section
```

选择该策略的索引必须具有带内容角色的`structure.json`，且原文、类型、页码和块集合须与SQLite一致。资料缺失或不一致时明确报检索错误，不静默退回旧的无条件邻块扩展。该策略内部管理正文与表格关联，暂不与独立的`RAG_TABLE_RETRIEVAL_ENABLED=true`表格扩展阶段叠加，以免非正文再次触发扩展；重排仍可用于选择主命中。

默认策略仍为`same_page`，本轮没有修改本机私有配置、切换PyMuPDF默认索引或部署服务器。113块资料仍为分类与固定主命中实验资料，尚未建立对应新向量索引；启用新的完整检索流程前需要准备匹配的索引。程序路径已接通，不等同本轮已经切换网站。

## 验证

自动测试覆盖可靠小节无需续句、跨页同小节、续句不重复触发兜底、小节预算耗尽不兜底、各类非正文独立、未知内容独立、正文续句的限制、正文可补入完整表格、原文目录校验及检索器策略分流。

本次32题共261次投影主命中处理：169次可靠正文走小节补全，86次非正文保持独立，6次不确定块保持独立。全部主命中保留、无重复来源，单条和总字符上限均通过；资料与网站私有配置未改变。本篇实际样本没有触发续句兜底，该路径由模拟可靠/不可靠章节、续句和跨页边界的测试覆盖。上述数量是处理次数，不是题目数或回答质量分数。
