# 统一审校：排版兼容、局部证据边界与输出预算

## 修改范围

18题提出的相对量限定正确，但短引句把MinerU的LaTeX单位转成正常排版，并改变句首The的大小写。引文定位新增有限的显示规范化：白名单字体包装、成对数学定界符、单位整数指数、连字符/负号显示和定冠词大小写。保留数字、比较符号、否定词、变量大小写及未识别的TeX。不是语义模糊匹配；未知差异仍拒绝，科学事实支持仍需模型核查。保存原始引句与证据哈希，不改写论文原文。共享引文规范化被所有使用该函数的审校版本使用。

24题的排名修正含真实论文来源，并以context表示“所给证据没有排名依据”。旧规则只要supported单元含context就拒绝，误拦截了合理的局部证据边界。现允许两者共存，但要求回答和context贡献都明确局限于所给/当前证据、包含不足或无法确定的说明、同时存在真实文字或图像来源。未知/不匹配来源依然失败；context不能单独证明科学事实，也不能声称整篇论文没有某项结论。这只是机械范围约束，不保证语义判断无误。

预算配置接受的上限从32,768提高到65,536；默认仍是32,768。本次31题通过验证脚本显式使用65,536，单次等待300秒、整题600秒，避免提高Token预算后仍被旧等待时间截断。配置校验允许等待最多360秒，但线上进程本身的总时限未改，也未切换网站默认审校版本。验证脚本增加独立参数及实际生效预算记录，不将实验参数误记成默认配置。

DeepSeek官方[模型列表接口说明](https://api-docs.deepseek.com/api/list-models/)提供max_output_tokens能力字段；最终能否在当前服务使用更高预算，以本次实际调用结果为准。Token上限不等于实际用量，不保证提高后纠错质量提升。
