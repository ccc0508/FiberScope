## 本轮修复

1. 总览链接中的小数、非数值或超大页码会导致API参数错误。前端现在只接受API允许范围内的正整数，其他值按第一页处理；超过实际总页数的有效页码仍回到第一页。
2. 平板布局中，靠近右侧的筛选菜单可能越界。菜单现在按页面实际可用宽度向左调整；选项定位仅滚动菜单内部，不滚动整页。
3. 手机导航增加Escape关闭、打开时的焦点定位、Tab循环和关闭后的焦点返回；导航打开时背景内容不可交互，切回桌面宽度自动关闭遮罩状态。
4. 修正1200px以下统计卡片说明文字错误继承30px字号的问题，说明文字恢复正常正文大小。
5. 再生纸浆筛选器外层的HTML标签会在选择选项后再次触发按钮，造成菜单重开。改为普通分组容器，保留筛选按钮自身的无障碍名称；回归使用真实鼠标选择并等待菜单关闭。

```powershell
npm --prefix frontend run build
```

```powershell

npx --yes --package @playwright/cli playwright-cli -s=fiberscope-audit run-code --filename frontend/scripts/browser-audit.js
```
