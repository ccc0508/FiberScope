# 性能预测接入

侧栏“性能预测”进入 `/prediction`。服务器采用现有子路径时，入口为 `/fiberscope/prediction`。

## 使用

- 实测纤维指标：选择树种，填写标有 `*` 的指标；其余可留空。百分比使用0—100口径。
- 只有打浆度：选择树种，填写打浆度（°SR），不是打浆转数。输入需大于0、不超过100。
- “填入示例”在实测模式使用交付包 `demo_input.csv` 中该树种第一条记录；打浆度模式填入50 °SR。
- “开始预测”返回9项纸张性能。打浆度模式另外显示12项中间纤维预测。
- 编辑任意输入会取消旧请求并清除旧结果，避免把上一组结果当作当前结果。
- 点击预测时统一检查输入，所有缺失或超限项同时显示红框与字段说明，并显示错误提示条；保留首个错误项的浏览器原生提示。
- 打浆度超过100会在网页内明确提示并阻止请求；接口错误也显示在提示条、表单和结果区，包含可用的请求编号。
- “导出结果”输出带UTF-8 BOM的CSV，同时保留输入、模型版本、单位、状态、单步R²及限制。
- 绝对值达到10⁹或小到按当前小数位会显示为0的非零预测值采用科学记数法。10⁹仅为显示阈值，不是物理极限；不封顶、不改动预测值，CSV仍导出原始计算值。

## 科学口径

仅支持针叶木、阔叶木纯浆，不支持复配和再生纸浆。所有结果为模型估算，不写入实验数据库。
直接预测使用 JSON 中的原始尺度系数：`intercept + sum(coef * feature)`；`log10=true` 时还原为 `10**value`。
打浆度通过每项纤维的二次公式再进入纸张模型。模型参数保持交付版本，不重新训练。

纸张表中R²来自 `nested_r2`，低于0.4的指标仅供参考；它不是准确率或本次预测的置信度。
直接预测中，模型可靠且所需输入均未超范围时标记“可参考”；超范围的相关结果标记“外推参考”。
非物理负值原样返回并标记“不适用”，不截断或伪造数值。
打浆度整链没有独立评测，全部纸张结果标为参考；不会把单步R²当作整链精度。
同时检查打浆度范围、第二步所用纤维范围，并注明低可靠性中间纤维影响的目标。
单位沿用现有指标目录：透气度单位暂定，耐折度单位未确认。

## 接口

接口均位于 `/api/v1/prediction`，沿用应用的请求编号与错误结构，不访问数据库。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/metadata` | 树种、训练范围、必填指标、示例、样本量、模型版本及限制 |
| POST | `/fiber` | 实测纤维指标预测 |
| POST | `/degree` | 打浆度整链预测 |

打浆度请求示例：

```json
{"species":"softwood","degree":50}
```

纤维请求为 `{"species":"softwood","features":{...}}`，features使用metadata返回的英文key。
树种还接受中文及0/1；未知树种、缺必填指标、负数、非有限值、物理范围错误、未知字段返回422。
超出训练范围但仍符合物理范围的输入允许计算，同时给出外推提示。
模型文件缺失返回503。计算溢出返回422，不向客户端暴露服务器路径。
模型版本为两份JSON内容合并后的SHA-256前16位，用于追溯交付参数。

## 发布

不需要新增Python依赖、数据库迁移、独立进程或公网端口。沿用现有FastAPI服务与Nginx。
每个发布版本必须包含：

```text
backend/app/prediction.py
backend/app/main.py（已注册预测路由）
deploy/model_coefficients.json
deploy/degree_to_fiber_coefficients.json
deploy/demo_input.csv
frontend/dist/（包含新预测页面的构建）
```

模型和示例随仓库发布，由服务从项目根目录的 `deploy/` 读取。

在frontend目录运行 `npm run build -- --base=/fiberscope/`，将产物放入新版本原有前端位置。
保留旧版本用于回退，按既有发布流程切换current软链接，再执行 `sudo systemctl restart fiberscope`。
现有 `/fiberscope/api/` 代理可直接使用。根路径部署使用默认 `npm run build`。
更新模型后同样需要重启后端，以清除进程内系数缓存。

部署验收：访问 `/fiberscope/api/v1/prediction/metadata`，再以JSON提交50 °SR到
`/fiberscope/api/v1/prediction/degree`；应返回9项纸张结果、12项纤维结果和整链限制。
在浏览器点击“填入示例”“开始预测”“导出结果”，同时检查原页面仍能访问。
