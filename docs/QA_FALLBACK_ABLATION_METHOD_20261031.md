# 仅删除回退额外邻块：固定证据实验方案

2026-10-31。用户要求“只去掉25次回退额外补入的邻块”。本轮不使用113块分类版，不改原107块、主命中、分组和引用编号，不重新执行上下文补全。网站默认配置保持不变。

## 唯一输入改动

从封存的`section-context-20261031`小节补全臂读取完整证据。找出模式为`same_page_fallback`的25次处理，仅在对应证据组中移除额外邻块。以下内容不得删除：原前8主命中中的任意一块、独立属于正常小节证据组的原文、没有由回退加入的内容。

每组保留原引用编号、主命中顺序、分数、原文及来源位置；未发生删除的证据必须逐字段相同。对确有删除的证据，只更新该组文字、原文块列表和相应页码，不改变其他组。按原连接规则移除片段，不总结或改写剩余原文。删除释放的空间不用来加入任何新片段，也不再运行候选排序。

25次回退涉及10题，并不表示删除25道题或25个独立片段。一些相邻块本身是主命中，或者已在其他证据中保留，因此不能删除。准备阶段记录实际删除的“题目×原块”、字符数和受影响证据组。

## 对照与判读

- 两臂均新答32题，每题独立工作进程。对照使用原封存完整证据，实验使用仅删邻块的证据；旧答案不作为本轮答题对照。
- 10题输入实际变化，另22题完整输入相同。主报告同时呈现全部题、实际删块题和相同输入题的比较；相同输入题的变化反映生成与裁判波动，不能归功于删块。不会把该波动作为统计校正系数。
- 原DeepSeek模型别名、High、提示词、输出格式、引用验证和最多两次生成保持不变；单题最长300秒。每对完成后再执行下一题，交替提交顺序。
- 只用原Jev五项规则，独立评分每份新答案。最多3次尝试、首个有效结果，不择优，不把缺失记零，不生成加权总分。
- 8000/24000字符上限保留；本轮仅做删除，原候选预算状态仅作历史诊断，不代表重新分配过预算。没有新增PDF解析、Embedding、检索、重排或分类调用。

单篇论文的一轮开发评测不能证明稳定效果；保留逐题新回答、全部评分尝试、费用未知项和来源指纹。即使删块题提高，也需区分具体证据使用变化和随机输出变化。
