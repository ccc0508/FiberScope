# 统一审校 v3.1：减少合理修改被误拦截

本次修改校验与核查记录补齐，未重新生成32题答案，未调用Jev，未更新任何既有评分，未部署服务器或切换默认审校版本。

## 改动

1. 局部证据范围支持“所给摘录、现有结果、所供方法”等说法。只消去明确的“不推断全文绝无…”否认断言；实际全文缺失断言仍拒绝。这仍是有限句式检查，不是语义证明。
2. 将测量推断边界单独识别：必须标记measurement，回答明确相对/归一化比例不能代表绝对数量，同时有可定位的真实方法引句支持相对量的计算。context不能单独证明科学事实，来源、引用、修改对象检查仍执行。该规则目前只覆盖相对量到绝对量的限定，不声称覆盖所有方法学推断。
3. 详细原句坐标错误时，仅在规范化引句唯一命中一个完整原文句子时由程序修复坐标，保存前后位置。不改来源、结果对象、真假判断；多处匹配和虚构引句仍不通过。
4. 修复因果路由误触发：不再把“因此…而…”或跨句的“因…而…”误当成多结果因果链。“导致/引起/因为…而…”等真实因果表达仍检查。该路由修复为共享逻辑，其他版本也会使用。
5. 缺失comparison_scope时，可在同一审校请求剩余时间内最多补调一次DeepSeek，只返回比较字段和理由。上限8192输出Token，其他审校预算不扩大；剩余不足5秒不调用。不允许修改答案、issues、来源、数值或原判断；unclear/different_scope仍不放行替换句。补齐不保证成功，失败保留初次结果和未完成状态，不自动重试。保存请求/响应哈希、补丁理由、用量与实际调用次数；额外调用用量未知时总用量记未知，保留已知主调用用量。
