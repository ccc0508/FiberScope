# 按陈述统一组织审校

新增可选`v3_unified / bounded-corrective-review-v3.0-unified`，与旧实验版v3不同。默认仍为v1，未部署服务器。

模型只输出issues、requirements、units。每条原始陈述最多一个unit，每条拟议替换陈述另有一个unit。一个unit集中保存原句全文/目标编号、检查方面、共享来源及各自贡献、统一判断与关键理由；详细因果结果及完整原句位置附在unit内。模型不再输出并行的claim_checks、relation_checks或comparison_checks。缺少整体回答部分继续由requirements记录，避免只能检查已经写出的句子。

新的基础指令直接编写，没有累加旧版各层提示词。程序给出重点陈述和方面，因果及比较详细指引按实际草稿信号加载，测量和排名沿用条件触发。基础指令保留扫描其他隐含风险的职责，模型可为未标记陈述新增unit。该入口有推理成本，也不保证不漏检。

所有unit检查事实和引用；其他方面按需列出。共享reason应说明源文与回答之间的实际差异，checked只是模型声明检查过哪些方面，不是各方面独立的可信证明。程序检查路由所要求的方面是否存在、完整原句及引句位置、结果列表内部一致性；语义仍由模型判断。

来源引句不重复记录在不同审校列表里。原有issues仍包含实际修改依据，以便独立验证和补查后的重新应用；因此没有声称消除了全部字段重复。比较引用补全继续使用原有安全逻辑：程序从unit派生内部比较映射，不新增模型输出；只有不改文字、同口径、真实引句支持的引用缺失可以自动补齐。内部兼容日志的claim_checks/relation_checks为空，比较映射注明由程序组织。

保留原句全文绑定、替换句独立核查、图像来源标识、引用校验、需求台账和补查预算。无效原句unit不能授权修改；重复目标、错指句子、无依据引句、未核查替换句、必要方面缺失、因果结果自相矛盾均不默认通过。允许一处失败而保留其他独立有效修订。单位上限48条；详细因果仍最多3条原句/3条替换句、每句6个结果，超额标记不完整。

## 验证范围

冻结第18、24、31、32题的初始草稿与MinerU/Qwen图文证据，对照旧版v2_ranking和统一版各一次。模型DeepSeek Flash High、32768输出上限、两次审校/一次补查上限、证据预算不变；不提供标准答案、不调用Jev、不挑选重复运行中最高结果。这是局部开发验证，不是完整32题评分或稳定性证明。

另以明确标注的合成来源验证普通数值查询、程序未标记的隐含范围外推、源文支持的多结果因果。合成案例不计入正式题集。原始运行目录为`.rag-data/evaluations/unified-20261104`。

三个人工构造对照均符合预期：普通数值答案保持；未经程序重点标记的“所有植物纤维”外推被改回漂白软木硫酸盐浆及实验条件；有原文支持的双结果因果保持，没有统一弱化因果。它们只说明入口可工作，不证明真实论文的泛化。

## 尚未解决的边界

- 引文受OCR字符、上标等影响，模型改写后不能通过原文精确定位。不能直接把不匹配引文默认视为有效。
- 详细因果仍依赖模型填完整句的字符位置，填错会使记录无效；来源多、关系复杂时仍会遗漏方面或扩大结果对象。
- context只表达上下文缺失，不能为supported科学陈述背书。24题需为保留的各项关系给出真实来源，不能只以“删掉排名词”通过。
- 同句来源集中后，推理负担并未随JSON字段数量同步下降。31题证明截断仍在；尚未证明成本或质量稳定提升。
- 单元合并没有替代全局需求台账；一个正确的单元也不能证明整个回答已完整。

本轮完成结构改造和真实验证，暂以v3_unified保留为可选实验版本，未切换网站/服务器默认配置。下一轮应优先处理可靠引文/完整句定位与替换句全量关系核查，再做配对重复验证；不继续盲目加大预算或叠加审校指令。
