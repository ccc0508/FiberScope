# 网站文献问答切换到 Agentic RAG

2026-11-06，本地网站默认使用已评测的目录直供 Agent。旧 AnswerService 和历史结果保留。

## 行为

- `LITERATURE_ENGINE=agent`（默认）接入 `scripts/run_literature_agent.py`，与当前评测共用 AgentLoop、模型配置和所选论文库。
- 每题独立上下文，初始提供完整精简目录；最多10次模型调用、8次工具调用、2次检索，总预算240秒。接口超时配置应为300秒。
- 后台执行及并发限制、幂等提交、公共历史、评价和导出继续使用原 HistoryStore。
- 保存完整 Agent 状态、模型调用、工具轨迹和证据账本；引用使用每题不可变编号，不重新压缩编号。
- 文字与图片引用支持PDF定位和图片缓存；计算引用标注为计算结果，不显示伪造的PDF链接。
- 完成复核只代表复核步骤完成，不保证事实正确；未完成运行记为失败，保留诊断，不能伪装为成功。

## 验证

- 55项后端相关测试通过，覆盖新旧入口、引用适配、失败状态、历史保存和工具循环。
- 前端类型检查及生产构建通过。
- 实际HTTP提交Li 2023问题，完成检索和复核，保存回答、引用及完整Agent轨迹；再次读取历史内容一致。
- 本地入口：`http://127.0.0.1:4173/literature`，后端 `127.0.0.1:8000`。

## 回退与部署范围

在私有 `backend/.env.literature` 中设置 `LITERATURE_ENGINE=legacy`，重启后端即可回退；无需删除历史、索引或新轨迹。

本轮切换本地网站并同步代码到GitHub，不代表公网服务器已更新。服务器需要部署代码、匹配的MinerU/Qwen论文库与私有模型配置后再验收，不能仅更新入口却沿用不兼容的旧索引。
